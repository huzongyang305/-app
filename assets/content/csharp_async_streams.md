**教材衔接：最小可运行示例**

先用 IAsyncEnumerable 跑通最小示例，然后只改一个与 IAsyncEnumerable 相关的取值：

```csharp
async IAsyncEnumerable<int> Countdown(int from)
{
    for (int i = from; i > 0; i--)
    {
        await Task.Delay(10);
        yield return i;
    }
}

await foreach (var value in Countdown(3))
{
    Console.WriteLine(value);
}
```

- **要点**：C# 中按需异步产生多个值的流式接口，可配合 await foreach。
- **IAsyncEnumerable 的边界**：只在「C# 中按需异步产生多个值的流式接口，可配合 await foreach」这一前提下成立，换输入或换环境要重新验证。

### 考点 8：`CancellationToken`

- **要点**：协作式取消令牌：传进异步方法后，调用方取消时任务在检查点退出，避免白干活。
- **CancellationToken 的边界**：易错：客户端断开后后台任务还在继续跑；正确做法是把 CancellationToken 一路传到最底层调用。

### 考点 9：`异步流`

- **要点**：按时间依次产出多个值的数据序列，消费者可以逐项等待和处理。
- **异步流 的边界**：易错：线程被占用，吞吐明显下降；正确做法是用 await foreach 与异步 API，避免 Result 和 Wait。

### 考点 10：`取消`

- **要点**：在任务不再需要时停止协程、请求或后台工作并释放资源。
- **取消 的边界**：易错：客户端断开后后台任务还在继续跑；正确做法是把 CancellationToken 一路传到最底层调用。

### 考点 11：排错——用 async void 代替 async Task

- **现象**：异常无法被捕获，调用方也无法等待。
- **处理**：除事件处理器外一律返回 Task 或 ValueTask。

### 考点 12：排错——忘记传递取消令牌

- **现象**：客户端断开后后台任务还在继续跑。
- **处理**：把 CancellationToken 一路传到最底层调用。

- **辨析点**：`IAsyncEnumerable` 的定义是 C# 中按需异步产生多个值的流式接口，可配合 await foreach；`取消` 的定义是 在任务不再需要时停止协程、请求或后台工作并释放资源。
