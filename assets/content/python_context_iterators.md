```python
class Counter:
    def __init__(self, limit):
        self.limit = limit
        self.value = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.value >= self.limit:
            raise StopIteration
        self.value += 1
        return self.value

print(list(Counter(3)))
```

- **辨析点**：`上下文管理器` 的定义是 用 with 语法在代码块前后自动执行获取与释放资源的协议；`资源` 的定义是 Agent 可通过协议读取或操作的受控对象，访问范围必须经过授权。
- **答题要求**：面对 `Python 上下文管理器与迭代器协议` 的题目，先判断描述的是 `上下文管理器` 还是 `资源`，再归到对应定义，最后写出一个会让该定义失效的边界输入。

### 考点 14：排错评分点

- **现象分**：能写出 异常路径资源泄漏，而不是只写“程序有错”。
- **证据分**：保留触发 自定义上下文管理器不处理异常 的输入、版本和错误原文。
- **修复分**：按 进入与退出成对处理，异常要继续向外传播 只改一处，并同时回归正常路径与边界路径。
