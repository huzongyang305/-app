## C++ 基础机制速览

### 编译、链接与头文件

C++ 源文件先经过预处理、编译和汇编，再由链接器合并目标文件和库。头文件通常放声明，源文件放定义；`#include` 在预处理阶段展开，头文件保护或 `#pragma once` 防止重复包含。声明告诉编译器名字和类型，定义提供实体，链接期才能发现未定义符号。理解这个流程能区分语法错误、类型错误和链接错误。

### 值、引用与指针

值语义会复制对象，引用是已有对象的别名且必须初始化，指针保存地址并可以为空。函数参数使用 `const T&` 可以避免复制又禁止修改；需要修改调用方对象时使用 `T&`；需要表达“可能没有对象”时使用指针或 `std::optional`。`const` 放在不同位置含义不同，`const T*` 表示不能通过指针修改对象，`T* const` 表示指针本身不能改。

### 函数、重载与作用域

C++ 支持函数重载、默认参数、内联函数和命名空间。重载依据参数类型和数量选择，返回类型不参与重载。默认参数只能在声明中出现一次，且应放在参数列表末尾。变量的作用域决定名字可见范围，生命周期决定对象何时创建和销毁；局部对象离开作用域时自动析构，这是 RAII 的基础。

### RAII、智能指针与异常安全

RAII 把资源获取放在构造函数、释放放在析构函数，让异常和提前返回都不会泄漏资源。裸 `new/delete` 容易漏删、重复释放或在异常路径上泄漏，现代 C++ 优先使用 `std::unique_ptr`、`std::shared_ptr` 和标准容器。`unique_ptr` 表达独占所有权，`shared_ptr` 通过引用计数共享所有权，但要避免循环引用；`weak_ptr` 可以观察 shared 对象而不延长生命周期。

### STL、迭代器与算法

标准库把容器、迭代器和算法分离：容器负责存储，迭代器提供统一访问方式，算法负责排序、查找、变换和聚合。`vector` 连续存储、随机访问快，`list` 适合频繁中间插入，`map` 有序且查找 O(log n)，`unordered_map` 平均 O(1) 但不保证顺序。修改容器结构可能使迭代器失效，使用前要查清规则。范围 for、lambda 和标准算法能让代码更短，但也要关注复制、捕获方式和复杂度。

## 考点精讲：把测验题还原成判断过程

本课有 4 个判断点。先自己作答，再看「判断依据」；如果结论正确但理由不完整，回到正文对应章节补足概念。

### 考点 1：把函数声明与定义分开写成 .h 与 .cpp，主要目的是？

- **正确判断**：让多个源文件共享接口声明，实现只编译一次
- **判断依据**：头文件提供声明，告诉编译器函数的名称、参数和返回类型；实现放在源文件中编译成目标文件，由链接器合并。这样修改实现时其他文件只需重新编译依赖，也避免了把实现重复展开进每个翻译单元导致的重复定义问题。声明与实现分离是 C++ 多文件工程的基础。
- **迁移检查**：如果给某个错误选项去掉一个限定词，它会不会变成正确？说明理由。

### 考点 2：C++ 中按值传递参数的特点是？

- **正确判断**：函数拿到实参的副本，修改形参不影响调用方变量
- **判断依据**：按值传递会复制实参，函数内部的修改只作用于副本；对于大对象，复制会带来额外开销，因此常用 const 引用避免复制。若确实需要修改调用方变量，应显式使用引用或指针参数。理解复制语义，才能解释为什么函数内交换了两个局部变量、外面却毫无变化，也能判断何时需要返回新值而不是就地修改。
- **迁移检查**：遮住选项，只根据定义复述一次答案，再回来看哪个选项与复述一致。

### 考点 3：函数重载（overload）指的是？

- **正确判断**：同名函数根据参数列表不同提供多个实现
- **判断依据**：重载允许同名函数以参数个数、类型或顺序区分，编译器根据实参选择匹配的版本，返回类型本身不参与区分。它与运行时的虚函数多态不同：重载在编译期解析。若两个重载只差返回类型，编译器会报错；设计重载时应保证各版本的语义一致，避免调用者需要猜测某个实参会落到哪个实现上。
- **迁移检查**：遮住选项，只根据定义复述一次答案，再回来看哪个选项与复述一致。

### 考点 4：示例中 square(7) 的调用结果是？

- **正确判断**：49，函数把参数相乘后通过 return 交回结果
- **判断依据**：square 接收 int n 并按值复制 7，返回 n * n 即 49，main 再把结果交给 cout 输出，于是看到 square(7)=49。函数名与变量名不在同一命名空间层级，不会因此冲突；真正需要检查的是参数类型、返回值类型以及是否漏写 return。
- **迁移检查**：把题干里的一个条件换成边界值，原来的结论还成立吗？写出判断过程。
