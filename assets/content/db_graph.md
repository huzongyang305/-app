## 代码/协议/SQL 示例

### 最小可验证示例

**教材衔接：最小可运行示例**

先用下面的示例确认 图数据库 的基线，再只改一个与 Cypher 相关的值：

```sql
WITH RECURSIVE edges(src, dst) AS (
  VALUES ('a', 'b'), ('b', 'c'), ('c', 'd')
), walk(node, depth) AS (
  SELECT 'a', 0
  UNION ALL
  SELECT edges.dst, walk.depth + 1
  FROM edges
  JOIN walk ON edges.src = walk.node
)
SELECT node, depth FROM walk ORDER BY depth;
```

**教材衔接：预期输出**

```text
node | depth
a    |     0
b    |     1
c    |     2
d    |     3
```
