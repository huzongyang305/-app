## 核心概念定义

| 术语 | 一句话说明 |
| --- | --- |
| `for` 循环 | 把一组已知数量的东西逐个处理一遍（按点名册点名：名单上有几个人就点几次） |
| `while` 循环 | 只要条件为真就反复执行，直到条件变假（等水烧开：没开就继续等，开了就停） |
| `range()` | 生成一段整数序列，用来控制循环次数（像楼梯的台阶编号，从第几级到第几级） |
| `break` | 立即结束整个循环，跳到循环后面（找到东西就不找了，直接走人） |
| `continue` | 跳过本轮剩余语句，进入下一轮循环（翻到一页空白就跳过去，继续翻下一页） |
| 嵌套循环 | 循环里面再套一层循环（日历：外层是月，内层是日） |

## 原理与运行机制

### 循环就像重复做同一件事

想象你每天早上要刷牙。这件事的步骤是固定的：挤牙膏、刷 2 分钟、漱口。你不需要把"刷牙"这个动作写 365 遍——你只需要知道"每天都要做"，然后重复执行。

编程里的循环也是同样的道理。当你想让计算机重复做某件事时，不用把代码复制粘贴很多遍，而是用循环告诉它："把这段代码执行 N 遍"或者"一直做到条件不满足为止"。

### for 循环的执行流程

```text
开始
 ↓
取出序列中的下一个元素
 ↓
有元素吗？── 没有 → 结束循环，执行循环后面的代码
 ↓ 有
执行循环体（缩进的代码）
 ↓
回到"取出下一个元素"
```

`for` 循环的工作方式很简单：有一个序列（比如一组数字、一个列表），循环每次从里面拿出一个元素，交给循环体处理，拿完了就自动结束。

### while 循环的执行流程

```text
开始
 ↓
检查条件是否为真
 ↓
为假 → 结束循环
 ↓ 为真
执行循环体
 ↓
回到"检查条件"
```

`while` 循环不关心"有多少个元素"，它只关心"条件还成不成立"。所以你必须自己保证循环里有东西在改变条件，否则条件永远为真，程序就卡住了——这就是**死循环**。

### 从最简单的 for 开始

先看一个最基础的例子：

```python
for i in range(3):
    print(i)
```

输出：

```text
0
1
2
```

`range(3)` 产生 0、1、2 三个数字（注意不包含 3），`for` 依次把每个数字赋给变量 `i`，然后执行 `print(i)`。

### 加上累加逻辑

```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)
```

执行过程拆解：

- 第一轮：`i = 1`，`total = 0 + 1 = 1`
- 第二轮：`i = 2`，`total = 1 + 2 = 3`
- 第三轮：`i = 3`，`total = 3 + 3 = 6`
- 循环结束，输出 `6`

### 用 while 实现同样的事

```python
total = 0
i = 1
while i <= 3:
    total = total + i
    i = i + 1      # 别忘了这行，否则 i 永远是 1
print(total)
```

对比 `for` 版本，`while` 需要你手动管理循环变量 `i`：先赋初值，再在循环体里更新它。好处是条件可以写得很灵活，坏处是忘了更新就会死循环。

### range() 的三种用法

```python
# Python 循环入门
range(5)          # 0, 1, 2, 3, 4

# 给两个参数：指定起点和终点（左闭右开）
range(1, 6)       # 1, 2, 3, 4, 5

# 给三个参数：加上步长
range(0, 10, 2)   # 0, 2, 4, 6, 8
```

记住一个口诀：**包含起点，不包含终点**。`range(1, 5)` 产生 1、2、3、4，不包含 5。这是新手最容易踩的坑。

### break 和 continue

`break` 用来提前退出循环——比如在一堆数据里找某个值，找到了就不用继续找了：

```python
for i in range(10):
    if i == 5:
        break
    print(i)
# 输出：0 1 2 3 4
```

`continue` 用来跳过本轮——比如遍历数字时跳过偶数：

```python
for i in range(6):
    if i % 2 == 0:
        continue
    print(i)
# 输出：1 3 5
```

### 嵌套循环

有时候你需要两层循环。比如打印一个 3×3 的坐标网格：

```python
for x in range(3):
    for y in range(3):
        print(f"({x},{y})", end=" ")
    print()
```

输出：

```text
(0,0) (0,1) (0,2)
(1,0) (1,1) (1,2)
(2,0) (2,1) (2,2)
```

外层循环每走一步，内层循环要完整跑一遍。所以 3×3 的嵌套循环，循环体总共执行 9 次。

## 典型应用场景

### 场景一：逐个打印列表中的元素

```python
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)
```

这是 `for` 循环最自然的用法——有一组东西，逐个处理。

### 场景二：计数 N 次

```python
for i in range(5):
    print(f"第 {i + 1} 次")
```

当你不关心具体的元素、只需要"重复 5 次"时，`range()` 是最好的搭档。

### 场景三：累加求和

```python
total = 0
for n in range(1, 101):
    total += n
print(total)  # 5050
```

准备一个累加器 `total`，每次循环把新值加进去。这是后续学数据处理的基础模式。

### 场景四：遍历文件每一行

```python
with open("data.txt", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

文件对象本身是可迭代的，`for` 每次读一行，不需要手动管理读取位置。

## 代码/协议/SQL 示例

### 最小可运行示例

```python
for i in range(3):
    print(i)
```

预期输出：

```text
0
1
2
```

### 完整示例：for + while + break + continue

```python
# 用 for 循环累加 1 到 5
total = 0
for n in range(1, 6):
    total += n
print(f"1 到 5 的和：{total}")  # 15

# 用 while 循环倒计时
countdown = 5
while countdown > 0:
    print(countdown)
    countdown -= 1
print("出发！")

# break 示例：找到第一个大于 3 的数就停
for x in [1, 2, 4, 5, 6]:
    if x > 3:
        print(f"找到了：{x}")
        break

# continue 示例：只打印奇数
for x in range(1, 7):
    if x % 2 == 0:
        continue
    print(x)
```

## 时间/空间复杂度或性能分析

对初学者来说，先关心**跑对**，再关心**跑快**。

不过你可以建立一个直觉：

- 循环执行 N 次，循环体里是简单操作 → 时间大致与 N 成正比，记作 O(N)。
- 嵌套循环，外层 M 次、内层 N 次 → 循环体执行 M×N 次，记作 O(M×N)。
- `for item in list` 和 `for i in range(len(list))` 速度差不多，但前者更易读。
- 在循环里反复用 `+=` 拼接字符串会每次都创建新对象，数据量大时明显变慢；更好的做法是收集到列表里，最后用 `"".join()` 一次拼好。

一句话原则：**先让程序正确运行，遇到性能瓶颈再用工具测量，不要凭感觉优化。**

## 常见误区与易错点

| 误区 | 实际现象 | 正确做法 |
| --- | --- | --- |
| `range(1, 5)` 以为会到 5 | 只产生 1, 2, 3, 4，少算一个 | 记住"左闭右开"，要包含 5 就写 `range(1, 6)` |
| while 循环忘记更新条件变量 | 死循环，程序卡住不动 | 每次循环体里都要有让条件趋向结束的操作 |
| 用下标遍历列表 | `for i in range(len(lst))` 代码冗长又容易越界 | 直接 `for item in lst`；需要下标时用 `enumerate()` |
| 循环里用 `=` 覆盖而不是 `+=` 累加 | 每次冲掉之前的结果，最后只剩最后一个值 | 分清"赋值"和"累加"，累加用 `+=` |
| 混淆 break 和 continue | 该退出时只跳过了本轮，该跳过时却退出了整个循环 | `break` = 彻底结束；`continue` = 跳过本轮 |
| 嵌套循环里变量名冲突 | 内外层用了同一个变量名，逻辑混乱 | 内外层用不同的变量名，比如外层 `i`、内层 `j` |

## 与其他知识点的关系

**先修依赖**：

- 《Python 输入与输出》：你需要会 `print()` 来观察循环输出，会 `input()` 来在循环中读取用户输入。
- 《Python 条件判断》：`while` 的条件、`break` / `continue` 后面的 `if` 都用到了 `if-elif-else` 和布尔表达式。

**后续衔接**：

- 《Python 列表与字典入门》：用 `for` 遍历列表和字典是下一课的核心操作。
- 《Python 函数》：循环经常写在函数体里，返回值可以终止循环的效果。
- 《Python 异常处理与文件操作》：用 `for line in file` 逐行读文件，用 `while` 做重试逻辑。

**概念对比**：

- `for` vs `while`：已知次数或有序列用 `for`；不知道要循环多少次、只知退出条件用 `while`。
- `break` vs `continue`：`break` 跳出整个循环，`continue` 只跳出当前这一轮。

### 自测 3

解释为什么下面这段代码会变成死循环，怎样修复？

```python
x = 10
while x > 0:
    print(x)
```

**参考答案**：循环体里没有修改 `x` 的值，`x` 永远是 10，条件永远为真。修复方法：在循环体里加上 `x -= 1`。

### 自测 4

**参考答案**：2, 5, 8。起点是 2，步长是 3，下一个是 5，再下一个是 8，再加 3 就是 11 已经超出终点 10，所以停止。
