## 典型应用场景

**教材衔接：经典应用**

```python
def largest_rectangle(heights):
    """柱状图中最大矩形面积"""
    stack, best = [], 0
    for i, h in enumerate(heights + [0]):        # 末尾加 0 保证全部弹出
        start = i
        while stack and stack[-1][1] > h:
            index, height = stack.pop()
            best = max(best, height * (i - index))
            start = index
        stack.append((start, h))
    return best

def daily_temperatures(temps):
    """每天要等几天才有更高温度"""
    result, stack = [0] * len(temps), []
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            result[j] = i - j
        stack.append(i)
    return result
```

- **栈里存值而不存下标**：典型现象是无法计算宽度或距离；正确做法是存下标，用时再取值。
- **比较符号写反**：典型现象是得到「更小」而不是「更大」；正确做法是明确单调方向并按题型验证。
- **弹出条件用 `<=` 还是 `<` 混淆**：典型现象是相等元素的处理不同；正确做法是按题意决定是否保留相等元素。
- **忘记处理栈中剩余元素**：典型现象是结果缺少尾部答案；正确做法是遍历结束后清栈或加哨兵。

```python
def next_greater(nums):
    """返回每个元素右侧第一个更大元素的下标，没有则为 -1"""
    result = [-1] * len(nums)
    stack = []                      # 存下标，对应值单调递减
    for i, value in enumerate(nums):
        while stack and nums[stack[-1]] < value:
            result[stack.pop()] = i
        stack.append(i)
    return result

print(next_greater([2, 1, 5, 3, 4]))   # [2, 2, -1, 4, -1]
```

**教材衔接：单调栈：找下一个更大/更小元素**

栈内元素保持单调（递增或递减），新元素入栈前弹出所有破坏单调性的元素——被弹出的元素正好找到了它的答案。

每个元素最多入栈出栈一次，复杂度 `O(n)`。

**教材衔接：单调队列：滑动窗口最值**

队列中存下标，值单调递减，队首就是窗口最大值；超出窗口范围的下标从队首弹出。

```python
from collections import deque

def max_sliding_window(nums, k):
    queue, result = deque(), []
    for i, value in enumerate(nums):
        while queue and nums[queue[-1]] <= value:
            queue.pop()                      # 维护单调递减
        queue.append(i)
        if queue[0] <= i - k:
            queue.popleft()                  # 移除滑出窗口的下标
        if i >= k - 1:
            result.append(nums[queue[0]])
    return result

print(max_sliding_window([1, 3, -1, -3, 5, 3], 3))   # [3, 3, 5, 5]
```

用堆也能做，但复杂度是 `O(n log n)`；单调队列是 `O(n)`。

**教材衔接：模板**

```python
from collections import deque

def next_greater(nums):
    """下一个更大元素的下标；不存在记 -1。"""
    result = [-1] * len(nums)
    stack = []                       # 存下标，对应值单调递减
    for i, value in enumerate(nums):
        while stack and nums[stack[-1]] < value:
            result[stack.pop()] = i
        stack.append(i)
    return result

def largest_rectangle(heights):
    """柱状图中最大矩形：单调递增栈，两端补 0 作哨兵。"""
    stack, best = [], 0
    for i, h in enumerate(list(heights) + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            best = max(best, height * width)
        stack.append(i)
    return best

def sliding_window_max(nums, k):
    """滑动窗口最大值：单调递减队列，队首即最大值。"""
    queue = deque()                  # 存下标
    result = []
    for i, value in enumerate(nums):
        while queue and nums[queue[-1]] <= value:
            queue.pop()              # 比新元素小的都不可能是最大值
        queue.append(i)
        if queue[0] <= i - k:        # 队首已滑出窗口
            queue.popleft()
        if i >= k - 1:
            result.append(nums[queue[0]])
    return result
```

### 考点 7：`单调栈`

- **要点**：维护单调顺序的栈，用于找下一个更大元素和直方图边界。
- **单调栈 的边界**：易错：O(n²) 超时；正确做法是改成单调栈 O(n)。

### 考点 8：`单调队列`

- **要点**：维护候选值单调顺序的队列，常用滑动窗口最值。
- **单调队列 的边界**：易错：结果取到窗口外的值；正确做法是检查 `queue[0] <= i - k`。

### 考点 9：`滑动窗口`

- **要点**：在时间轴上只统计最近一段窗口内的请求或事件，用平滑突发并限制瞬时速率。
- **滑动窗口 的边界**：网络延迟、超时与版本协商会改变行为，只在真实链路或多版本客户端上验证才算数。

### 考点 10：`下一个更大元素`

- **要点**：右边第一个比当前元素大的位置；用单调栈一遍扫完，复杂度 O(n)。
- **下一个更大元素 的边界**：结论随输入规模变化，小规模成立不代表大规模成立，需要重新测量。

### 考点 11：排错——栈里存值而不存下标

- **现象**：无法计算宽度或距离。
- **处理**：存下标，用时再取值。

### 考点 12：排错——比较符号写反

- **现象**：得到「更小」而不是「更大」。
- **处理**：明确单调方向并按题型验证。

### 考点 13：综合辨析——`单调栈` 与 `下一个更大元素`

- **辨析点**：`单调栈` 的定义是 维护单调顺序的栈，用于找下一个更大元素和直方图边界；`下一个更大元素` 的定义是 右边第一个比当前元素大的位置；用单调栈一遍扫完，复杂度 O(n)。
- **答题要求**：面对 `单调栈与单调队列` 的题目，先判断描述的是 `单调栈` 还是 `下一个更大元素`，再归到对应定义，最后写出一个会让该定义失效的边界输入。

### 考点 14：排错评分点

- **现象分**：能写出 无法计算宽度或距离，而不是只写“程序有错”。
- **证据分**：保留触发 栈里存值而不存下标 的输入、版本和错误原文。
