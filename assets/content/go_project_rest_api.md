### 复盘模板

- **忽略 http.Server 超时**：典型现象是慢连接耗尽资源；正确做法是设置读写和空闲超时。
- **错误直接写 500**：典型现象是客户端无法区分；正确做法是定义领域错误到状态码映射。
- **数据库句柄未关闭**：典型现象是连接泄漏；正确做法是defer db.Close 并管理生命周期。
- **goroutine 泄漏**：典型现象是进程无法退出；正确做法是用 context 取消并等待 goroutine。
