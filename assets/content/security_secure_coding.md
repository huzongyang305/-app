## 核心概念定义

| 术语 | 操作性定义 | 常见边界与风险 |
| --- | --- | --- |
| 输入校验 | 在信任边界检查类型、长度、格式和取值范围，拒绝非法数据。 | 类型检查挡不住外部输入：长度、范围和业务约束仍要在服务端校验，只信客户端就留下注入与越权风险。 |
| 输出编码 | 在输出到 HTML、SQL 或命令前按目标语境转义，防止注入。 | 易错：只按一种语境转义就复用到别的出口，HTML 里安全的内容到 Shell 或 SQL 仍会触发注入。 |
| 最小权限 | 每个账号、进程或服务只获得完成当前任务所需的权限，把泄露影响面降到最低。 | 易错：为跑通一次流程就把权限放到最宽，泄露时影响面同步扩大；扩权限要按当前任务所需重新划定。 |
| 错误处理 | 识别、传播并恢复异常或失败路径，避免错误被吞掉或扩大影响。 | 易错：把异常吞掉只回一行「出错了」查不到根因；反过来把堆栈、SQL 和文件路径原样返回给用户，又泄露了内部信息。 |
