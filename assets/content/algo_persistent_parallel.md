下面示例用于验证「持久化数据结构与并行算法」的最小输入、处理和输出。先原样运行，再只修改一个值：

```python
def linear_search(items, target):
    for index, item in enumerate(items):
        if item == target:
            return index
    return -1

print(linear_search([3, 5, 8], 8))
```

4. 修复后补边界、失败和重复执行测试。
