### 考点 7：`null`

- **要点**：基本类型不能为 `null`、不能当泛型参数；包装类可以，但拆箱时若为 `null` 会抛 `NullPointerException`。
- **null 的边界**：易错：`NullPointerException`；正确做法是写成 `"x".equals(str)` 或用 `Objects.equals`。

### 考点 8：`equals`

- **要点**：比较内容一律用 `equals`**；字符串不可变，每次「修改」都会产生新对象，循环拼接应使用 `StringBuilder`。
