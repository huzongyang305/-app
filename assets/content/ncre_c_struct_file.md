## 本节知识框架

**课程定位**：所属分类 `ncre`（全国计算机等级二级），课程主题 `二级 C：结构体、共用体与文件操作`，学习阶段 进阶，建议用时 55 分钟。

前面三课解决「一个值怎么算」，这一课解决「一条记录怎么表示、怎么串起来、怎么留在磁盘上」。二级 C 的程序设计题非常偏爱这条主线：给出学生或职工记录，要求建立链表、按条件查找、把结果写进文件再读回来。题目难的不是语法，而是要同时想清楚三张图——内存里成员怎么排、指针怎么把结点串成链、文件指针现在停在哪个位置。

把结构体想成一张表格的一行：`int num` 是一格，`char name[20]` 是一格，格子的顺序和宽度由你自己定。链表则是把这些行用绳结串起来：每一行除了自己的数据，还要留一个指向下一行的地址。文件操作解决的是「散会后这些行去哪儿」：写进去要按同一种格式，读出来才能还原。这三层一旦分开想，各层的错误就都成了可定位的小错。

**学完本课应当能够**

- 用三种方式定义结构体类型并声明变量，说明 `typedef` 省掉了什么。
- 判断一个结构体变量占多少字节，解释填充的作用。
- 写出头插法与尾插法的建表过程，并说明插入与删除时指针改动的先后顺序。
- 说出共用体与枚举的存储规则，指出共用体为什么不能同时保存多个成员的值。
- 选择正确的 `fopen` 模式串，用读写函数与定位函数完成一次「写后再读」的完整流程。

## 核心概念定义

| 术语 | 操作性定义 | 常见边界与风险 |
| --- | --- | --- |
| 结构体类型 | 由用户把若干不同类型的成员组合成的新类型，用 `struct` 加标签定义。 | 定义类型不占内存，声明变量才分配；以分号结尾，漏分号是常见编译错误。 |
| 成员 | 结构体里的一个数据项，通过圆运算符或箭头运算符访问。 | 成员名可以与别的变量重名，作用域限定在结构体内部。 |
| typedef | 给已有类型起别名的声明，`typedef struct Node NODE;` 之后可直接写 NODE。 | 别名只是换名字，不改变类型本身，也不省掉分号。 |
| 内存对齐 | 编译器为了让访问更快，在成员之间或末尾插入填充字节，使各成员落在合适的地址上。 | `sizeof` 得到的是含填充的总字节数，不等于各成员大小之和。 |
| 结构体数组 | 元素为结构体类型的数组，每个元素是一整条记录。 | 数组名同样是指针常量，成员访问写成 `arr[i].num`。 |
| 箭头运算符 | 通过结构体指针访问成员的写法，`p->num` 等价于 `(*p).num`。 | 圆运算符左边必须是结构体变量，箭头左边必须是指针。 |
| 链表 | 由结点用指针依次串起来的线性结构，逻辑上相邻、物理上不必相邻。 | 只有一个头指针，丢失头地址等于丢失整条链。 |
| 头插法 | 每读入一个新结点都把它插在链表前端，结果顺序与输入顺序相反。 | 必须先让新结点接住原头地址，再更新头指针，两步不能反。 |
| 尾插法 | 维护一个尾指针，把新结点接到表尾，结果顺序与输入一致。 | 结束时要把尾结点的 next 置空，否则读到脏地址。 |
| 删除结点 | 让前驱的 next 跳过被删结点，再归还其内存。 | 先改指针后释放；释放后再读该结点的 next 就取不到值了。 |
| 共用体 | 多个成员共享同一段存储区域的类型，所有成员起始地址相同。 | 同一时刻只有一个成员有效，写入新成员会覆盖旧值。 |
| 枚举 | 用名字表示一组整型常量的类型，第一个常量默认取 0，之后依次加一。 | 枚举常量是整数，不是字符串，不能直接当文本输出。 |
| 文件指针 | 指向描述文件信息的结构体对象的指针，类型为 FILE，由 fopen 返回。 | 打开失败返回空指针，不判空直接使用会崩溃。 |
| 文本文件与二进制文件 | 前者按字符存放、可读性好，后者按内存原样存放、体积小且无需转换。 | 模式串里带 b 才按二进制处理，读写函数要与打开方式配套。 |
| 缓冲区 | 写出的数据先在内存暂存，关闭文件或刷新时才真正落到磁盘。 | 只写不关文件，内容可能完全丢失。 |
| 文件位置指针 | 记录下一次读写发生的位置，可用 fseek、ftell、rewind 移动或查看。 | 写完想立刻读回，必须先把它移回开头。 |

## 原理与运行机制

### 定义、访问与整体赋值

结构体有四种常见写法，语义完全一样，只是省事程度不同：

```c
struct Student {
    int num;
    char name[20];
    float score;
};

struct Student s1;                      /* 用标签声明变量 */

typedef struct Student Student;         /* 起别名 */
Student s2;                             /* 之后不必再写 struct */

struct Point { int x; int y; } p1, p2;  /* 定义类型的同时声明变量 */
```

访问分两条路：变量用圆运算符 `s1.num`，指针用箭头 `p2->num`。因为解引用指针得到的就是变量，`p2->num` 与 `(*p2).num` 完全等价，括号不能省——圆运算符的优先级高于解引用，直接写 `*p2.num` 会被理解成先取 `p2` 的成员，那就错了。

同类型的结构体变量可以整体赋值 `s1 = s2;`，这是按字节复制整条记录；但**不能**用双等号比较内容，比较要逐个成员写，字符串成员还得用 `strcmp`。把结构体传给函数时，值传递会复制整条记录，成员越多开销越大，因此二级教材统一推荐传指针；反过来，函数返回一个结构体变量是合法的，可以一次带回多个值。

`sizeof(struct Student)` 通常不是 4 + 20 + 4 = 28，编译器为满足对齐会在成员间或末尾补填充。考试题目一般直接告诉你要按哪个字节数理解，或者只考「不等于简单相加」这个结论，不必自己算布局。

### 链表：先接后断

链表的结点类型必须能引用自己，靠的就是「结构体里放一个指向同类型结构体的指针」：

```c
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *next;
};

struct Node *make(int value) {
    struct Node *p = (struct Node *)malloc(sizeof(struct Node));
    if (p == NULL) {
        exit(1);                 /* 申请失败就不要继续写 */
    }
    p->data = value;
    p->next = NULL;
    return p;
}

void insert_front(struct Node **head, struct Node *newNode) {
    newNode->next = *head;       /* 第一步：新结点接住原表头 */
    *head = newNode;             /* 第二步：头指针改指新结点 */
}
```

插入的两步顺序是这道题的全部知识点。反过来写会先把原表头地址覆盖掉，后面 `newNode->next = *head;` 拿到的已经是新结点自己，链表当场断裂。删除结点同理：先把前驱的 `next` 改成后继地址，再 `free` 被删结点；顺序反了，取后继地址时那个结点已经归还给系统。

遍历用 `for (p = head; p != NULL; p = p->next)`，判断条件是「指针非空」而不是「指针的 data 非空」。用二级指针 `struct Node **head` 是为了在函数里改动调用者手里的头指针——这与上一课「想带回结果就传地址」是同一个道理。

### 共用体与枚举：省内存的两套规则

共用体所有成员从同一个地址开始，所占大小取最长成员（还要满足对齐），因此同一时刻只有一个成员存着有效值。典型用法是「一条记录里某几类字段互斥」：职工分为教师、职工、学生三种，各自的专业字段含义不同，就可以放进一个共用体，谁被选中就用谁。写 `u.d = 2.5;` 之后再读 `u.i`，读到的内容是同一块字节的另一种解释，不属于有效值。

枚举把一组整型常量起名，第一个默认是 0，之后依次加一，也可以显式赋值 `RED = 5` 然后后续从 6 开始。枚举变量存的是整数，直接打印数值可以，想要名字就得自己写查表函数——真题常在这里挖空。

### 文件：模式、读写、定位

打开文件只有一句话要记：**模式串决定权限，也决定文件是否被清空**。

- `r` 只读，文件必须存在，否则返回空指针。
- `w` 只写，存在则清空、不存在则创建。
- `a` 追加，写入永远接在末尾，不清空原内容。
- 加 `+` 表示读写都允许；加 `b` 表示按二进制处理。

字符级读写用 `fgetc` 与 `fputc`，行级用 `fgets` 与 `fputs`，格式化用 `fscanf` 与 `fprintf`（用法与 scanf、printf 一致，只是多了文件指针）。整块读写用 `fread` 与 `fwrite`，四个参数依次是「缓冲区地址、每个对象的字节数、对象个数、文件指针」，返回值是实际完成读写的项目数，用它判断是否读满最可靠：

```c
FILE *fp = fopen("data.bin", "wb");
if (fp != NULL) {
    struct Student arr[3];
    /* 填入数据后整体写出 */
    fwrite(arr, sizeof(struct Student), 3, fp);
    fclose(fp);
}

fp = fopen("data.bin", "rb");
struct Student back[3];
if (fp != NULL) {
    size_t got = fread(back, sizeof(struct Student), 3, fp);
    printf("%d 条记录\n", (int)got);
    fclose(fp);
}
```

文本方式下 `fprintf` 写出的内容人眼可读，二进制方式下 `fwrite` 写的是内存原样，两者不能混用同一个文件来回读写。

定位三件套各司其职：`ftell` 报当前位置距文件开头的字节数，`fseek` 按基准移动（起始、当前、末尾三种基准），`rewind` 直接回到开头并把结束标志复位。刚写完就要读回的文件，位置指针停在末尾，不 rewind 或不 fseek 就读不到任何内容——这一步在二级考试的操作题里单列给分。另一个高频坑是 `feof`：它是「上一次读操作之后发现已到文件尾」才为真，所以直接 `while (!feof(fp))` 会把最后一条记录处理两遍，正确做法是用读函数返回值判断。最后，`fclose` 会把缓冲区里的内容刷到磁盘并释放文件指针，漏掉它的程序可能看起来运行正常、文件却是空的。

## 典型应用场景

| 场景 | 典型输入或前提 | 用上的结论 |
| --- | --- | --- |
| 学生成绩表 | 一条记录含学号、姓名、三门成绩 | 结构体数组或链表，平均成绩用结构体返回值带回 |
| 动态插入新生 | 人数运行时才知道 | 结点用 malloc 建立，插入时先接后断 |
| 按条件查找 | 输入学号找记录 | 遍历比较成员，字符串条件交给 strcmp |
| 把统计结果存档 | 程序结束后要留档 | 只写模式打开，写完立即 fclose |
| 读回存档继续处理 | 上一次运行留下的文件 | 只读模式或加号模式打开，读的位置由定位函数决定 |
| 互斥字段省空间 | 同一记录不同类别字段含义不同 | 共用体承载互斥字段，用一个标签成员说明当前哪个有效 |

### 最小验证场景

写一个只有 20 行的闭环：定义含一个 int 与一个 char 数组的结构体，建两个结点串成链，用 `fprintf` 把每条记录写成一行文本，然后用 `rewind` 回到开头，用 `fscanf` 读回来打印。跑通之后依次改坏三处：删掉 `fclose`、把模式串从 `r` 改成 `w`、删掉 `rewind`。三处改动分别对应「文件是空的」「原内容被清空」「读不到数据」三种结果，做完这一轮，操作题里的三个扣分点就都有了身体记忆。

## 代码/协议/SQL 示例

**结构体数组排序并输出**

```c
#include <stdio.h>
#include <string.h>

struct Student {
    int num;
    char name[20];
    float score;
};

int main(void) {
    struct Student cls[3] = {{101, "Ann", 82.0}, {102, "Bob", 91.5}, {103, "Cid", 77.0}};
    int i, j;
    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2 - i; j++) {
            if (cls[j].score < cls[j + 1].score) {
                struct Student t = cls[j];
                cls[j] = cls[j + 1];        /* 同类型结构体可整体赋值 */
                cls[j + 1] = t;
            }
        }
    }
    for (i = 0; i < 3; i++) {
        printf("%d %s %.1f\n", cls[i].num, cls[i].name, cls[i].score);
    }
    return 0;
}
```

输出按成绩从高到低是三行 `102 Bob 91.5`、`101 Ann 82.0`、`103 Cid 77.0`。交换整条记录只要三次赋值，这就是「同类型结构体变量可以互相赋值」的实用价值。

**共用体的大小与有效成员**

```c
#include <stdio.h>

union Hold {
    int i;
    double d;
    char c;
};

int main(void) {
    union Hold u;
    printf("%d\n", (int)sizeof(union Hold));
    u.i = 65;
    printf("%d\n", u.i);
    u.c = 'A';
    printf("%d %d\n", u.c, u.i);   /* u.i 已不再是 65 */
    return 0;
}
```

大小取最长成员（这里是 double 的字节数，按对齐可能是 8）。最后一次打印里 `u.i` 的值不属于程序想表达的内容：写入 char 之后，整块字节里只有最低那一格被改过，作为 int 解释出来的结果与原来的 65 无关。

**文本方式写文件并读回**

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("score.txt", "w");
    if (fp == NULL) {
        printf("open fail\n");
        return 1;
    }
    fprintf(fp, "%d %s %.1f\n", 101, "Ann", 82.0);
    fprintf(fp, "%d %s %.1f\n", 102, "Bob", 91.5);
    fclose(fp);

    int num;
    char name[20];
    float score;
    fp = fopen("score.txt", "r");
    while (fscanf(fp, "%d %19s %f", &num, name, &score) == 3) {
        printf("%d %s %.1f\n", num, name, score);
    }
    fclose(fp);
    return 0;
}
```

两次 `fclose` 都不能省：第一次让内容真正落盘，第二次释放第二个文件指针。读回时用 `fscanf` 的返回值等于 3 作循环条件，比 `feof` 判断更可靠，也不会把最后一行读两遍。

**二进制块读写与定位**

```c
#include <stdio.h>

int main(void) {
    int data[4] = {10, 20, 30, 40};
    int back[4] = {0};
    FILE *fp = fopen("num.bin", "wb");
    fwrite(data, sizeof(int), 4, fp);
    rewind(fp);                       /* 回到文件开头才读得到 */
    size_t got = fread(back, sizeof(int), 4, fp);
    printf("%d %d\n", (int)got, back[3]);
    fseek(fp, -(long)sizeof(int), SEEK_END);
    int last = 0;
    fread(&last, sizeof(int), 1, fp);
    printf("%d\n", last);
    fclose(fp);
    return 0;
}
```

`got` 为 4、`back[3]` 为 40；`fseek` 以文件末尾为基准往回退一个 int 的长度，再读一次同样得到 40。这段把「写完立刻读要先定位」与「三种定位基准」都覆盖了，也是程序填空题的原型。

## 时间/空间复杂度或性能分析

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| 按成员访问结构体变量 | 常数 | 成员偏移在编译期就定好 |
| 整体赋值一条记录 | 与记录字节数成正比 | 复制整块内存，成员多时传指针更划算 |
| 链表按位置查找 | 与结点数成正比 | 只能从头顺着 next 走，没有随机访问 |
| 链表在已知位置插入或删除 | 常数 | 改两三个指针即可，不需要移动元素 |
| 顺序表插入 | 与后移元素个数成正比 | 这正是链表存在的理由 |
| 文本读写 | 需要格式转换 | 体积大、可读，格式化函数按字符解析 |
| 块读写 fread 与 fwrite | 一次搬一批 | 无格式转换，效率高于逐个 fscanf |

链表与数组的选择在二级题目里通常被题意指定，判分看的是指针操作顺序而不是复杂度；但公共基础的选择题会直接问「链表插入是否需要移动元素」，记住结论：插入与删除只改指针，查找需要从头走。

文件部分的性能账很简单：一次读写一整块远比逐个项目读写快，所以结构体数组存档优先用 `fwrite`；文本文件适合人工检查，二进制文件适合程序回读。考场里更值钱的是「别丢分」的时间——打开文件后第一件事判空，结束前最后一件事 `fclose`，这两步各写一行，操作题的文件分值基本稳了。

## 常见误区与易错点

- **结构体定义末尾漏分号**。花括号后的分号是语法必需，漏写会连带后面所有声明报错。
- **把类型当变量**。`struct Student;` 只是定义类型，不分配内存，也不会创建对象。
- **用双等号比较两条记录**。整体比较非法，字符串成员还要用 strcmp。
- **圆运算符与箭头运算符用反**。变量用圆、指针用箭头，`*p.num` 因为优先级而含义错误。
- **插入时先改头指针再接旧表头**。链表当场断裂，顺序永远是先接后断。
- **删除时先 free 再取后继**。释放之后读该结点的 next 已经不可靠。
- **申请内存不判空**。malloc 失败返回空指针，紧接着解引用就崩溃。
- **以为共用体能同时保存多个成员**。成员共享起始地址，写一个就覆盖另一个。
- **枚举常量当字符串打印**。它存的是整数，要输出名字得自己写映射。
- **用 w 模式打开还想保留旧内容**。w 会清空原文件，追加必须用 a。
- **文件打开失败不判空直接用**。fopen 返回空指针时使用它属于未定义行为。
- **写完立刻读却不定位**。位置指针在末尾，不 rewind 也读不到内容。
- **用 while (!feof(fp)) 控制循环**。最后一条记录常被处理两遍，改用读函数返回值判断。
- **省掉 fclose**。缓冲区没刷新，文件看起来是空的。

## 自测题与参考答案

### 题目 1

若有定义 struct Student s; struct Student *p = &s; 则访问成员 num 的正确写法是？

1. s.num 与 (*p).num，两者等价，也可写成 p->num
2. s->num 与 (*p).num，结构体变量也可以用箭头访问
3. 只有 p->num 一种写法，带圆括号的形式是非法语法
4. s.num 合法，但要访问指针成员必须先把指针解引用成变量再取下标

**参考答案**：A（s.num 与 (*p).num，两者等价，也可写成 p->num）

本题正确项是「s.num 与 (*p).num，两者等价，也可写成 p->num」。圆运算符用于结构体变量，箭头运算符用于结构体指针，而解引用指针得到的正是那个变量，所以三种写法指向同一块成员。干扰项「s->num 与 (*p).num，结构体变量也可以用箭头访问」不成立，箭头左边必须是指针类型，s 是变量，写 s->num 会直接编译报错。

### 题目 2

共用体变量所占的内存大小，以及它同一时刻能有效保存的成员个数，分别是？

1. 所有成员大小之和，能同时保存全部成员
2. 最长成员所占的字节数，同一时刻只能保存一个成员
3. 第一个成员的大小，能保存的成员个数与声明顺序有关
4. 与结构体完全相同，只是关键字换成了 union

**参考答案**：B（最长成员所占的字节数，同一时刻只能保存一个成员）

本题正确项是「最长成员所占的字节数，同一时刻只能保存一个成员」。共用体的所有成员共享同一起始地址，空间按最长成员准备，写入新成员会覆盖旧成员的值，因此任何时候只有一个成员是有效的。干扰项「所有成员大小之和，能同时保存全部成员」描述的是结构体的存储方式，两者的规则正好相反。

### 题目 3

若要以只写方式打开一个二进制文件，文件不存在时创建、存在则清空内容，fopen 的第二个参数应写成？

1. rb，表示以只读方式打开二进制文件
2. ab，表示以追加方式打开二进制文件，写入总是接在文件末尾而不清空原内容
3. wb+，表示以读写方式打开并清空或创建
4. wb，表示以只写方式打开二进制文件，不存在则创建，存在则清空

**参考答案**：D（wb，表示以只写方式打开二进制文件，不存在则创建，存在则清空）

本题正确项是「wb，表示以只写方式打开二进制文件，不存在则创建，存在则清空」。模式串里的 w 决定清空或创建，b 决定按二进制处理，两个字母正好对应题目的四项要求；带加号的 wb+ 虽然也能写，但同时开放了读权限，不属于只写。干扰项「ab，表示以追加方式打开二进制文件，写入总是接在文件末尾而不清空原内容」把清空换成了追加，这是真题用来区分 w 与 a 的经典写法。

### 题目 4

阅读下面的 C 代码，关于 newnode 插入后的链表，正确的说法是？

```c
struct Node {
    int data;
    struct Node *next;
};

void insert_front(struct Node **head, struct Node *newnode) {
    newnode->next = *head;
    *head = newnode;
}
```

1. 新结点接在表尾，原头指针保持不变
2. 头指针先指向新结点，再让新结点接住原表头
3. 新结点先接住原表头，然后头指针改指向新结点
4. 原表头被覆盖丢弃，链表长度保持不变

**参考答案**：C（新结点先接住原表头，然后头指针改指向新结点）

本题正确项是「新结点先接住原表头，然后头指针改指向新结点」。两句的顺序不能换：先让新结点的 next 保存原来的头地址，再把头指针更新，这样任何时刻链表都没有断链。干扰项「头指针先指向新结点，再让新结点接住原表头」正是把两行写反的后果，原表头地址在赋值那一刻就丢了，其余结点全部失联。

### 题目 5

填空：在 C 语言中，按「每个对象字节数乘以对象个数」一次性把文件中的数据读入内存缓冲区所使用的函数是 ________。

**参考答案**：fread

本题正确项是「fread」。它的四个参数依次是缓冲区地址、单个对象的字节数、对象个数与文件指针，返回值是实际完成读取的对象个数；与之配对写出的是 fwrite。fgets 一次只能读一行文本，fgetc 一次只读一个字符，两者都不属于块读写。

### 题目 6

把「写一段数据再把它读回来」的四个动作按先后排列：

1. 调用 fclose 关闭文件指针，让缓冲区内容真正落到磁盘
2. 用 fopen 得到文件指针，并判断它是否为空指针
3. 执行 fprintf 或 fwrite 把数据写出
4. 在读回之前用 rewind 或 fseek 把位置指针移回文件开头

**参考答案**：用 fopen 得到文件指针，并判断它是否为空指针 → 执行 fprintf 或 fwrite 把数据写出 → 在读回之前用 rewind 或 fseek 把位置指针移回文件开头 → 调用 fclose 关闭文件指针，让缓冲区内容真正落到磁盘

本题顺序是「用 fopen 得到文件指针，并判断它是否为空指针」 → 「执行 fprintf 或 fwrite 把数据写出」 → 「在读回之前用 rewind 或 fseek 把位置指针移回文件开头」 → 「调用 fclose 关闭文件指针，让缓冲区内容真正落到磁盘」。打开必须先判空，写完的位置指针停在末尾所以读回前要定位，fclose 放在最后，它同时承担刷新缓冲区的作用。

## 考点精讲

本课题库共 6 道题，下面逐题复述题干、正确项与判断依据。

### 考点 1：第 1 题

- **题目**：若有定义 struct Student s; struct Student *p = &s; 则访问成员 num 的正确写法是？
- **正确项**：A（s.num 与 (*p).num，两者等价，也可写成 p->num）
- **判断依据**：本题正确项是「s.num 与 (*p).num，两者等价，也可写成 p->num」。变量配圆运算符、指针配箭头运算符，解引用指针之后得到的就是变量本身。干扰项「s->num 与 (*p).num，结构体变量也可以用箭头访问」把箭头用在了变量上，属于类型不匹配的编译错误。

### 考点 2：第 2 题

- **题目**：共用体变量所占的内存大小，以及它同一时刻能有效保存的成员个数，分别是？
- **正确项**：B（最长成员所占的字节数，同一时刻只能保存一个成员）
- **判断依据**：成员共享同一起始地址，大小按最长成员准备，写入新的成员就覆盖旧值。干扰项「所有成员大小之和，能同时保存全部成员」说的是结构体，不是共用体；把关键字换成 union 并不会改变存储方式。

### 考点 3：第 3 题

- **题目**：若要以只写方式打开一个二进制文件，文件不存在时创建、存在则清空内容，fopen 的第二个参数应写成？
- **正确项**：D（wb，表示以只写方式打开二进制文件，不存在则创建，存在则清空）
- **判断依据**：w 负责清空或创建，b 负责按二进制处理，两者组合恰好满足题目要求，且不开放读权限。干扰项「ab，表示以追加方式打开二进制文件，写入总是接在文件末尾而不清空原内容」把 a 当成 w 使用，追加不清空。

### 考点 4：第 4 题

- **题目**：阅读下面的 C 代码，关于 newnode 插入后的链表，正确的说法是？struct Node { int data; struct Node *next; }; void insert_front(struct Node **head, struct Node *newnode) { newnode->next = *head; *head = newnode; }
- **正确项**：C（新结点先接住原表头，然后头指针改指向新结点）
- **判断依据**：两行语句的先后次序就是「先接后断」规则，任何时刻都不会丢表头地址。干扰项「头指针先指向新结点，再让新结点接住原表头」是写反之后的结果，此时原表头已经失联。

### 考点 5：第 5 题

- **题目**：填空：在 C 语言中，按「每个对象字节数乘以对象个数」一次性把文件中的数据读入内存缓冲区所使用的函数是 ________。
- **正确项**：fread
- **判断依据**：块读写的四个参数与返回值含义是本课要点，写出用 fwrite，读回用 fread，返回值给出实际完成的项目个数。逐行读文本用 fgets，逐个字符读用 fgetc，都不能一次搬整块数据。

### 考点 6：第 6 题

- **题目**：把「写一段数据再把它读回来」的四个动作按先后排列：
- **正确项**：用 fopen 得到文件指针，并判断它是否为空指针 → 执行 fprintf 或 fwrite 把数据写出 → 在读回之前用 rewind 或 fseek 把位置指针移回文件开头 → 调用 fclose 关闭文件指针，让缓冲区内容真正落到磁盘
- **判断依据**：判空在读写之前，写完必须定位才能读回，关闭放在最后负责刷新缓冲区。正确序号排列为 2 → 3 → 4 → 1。

### 高频考点小结

1. 运算符配对：变量用圆、指针用箭头，`p->x` 与 `(*p).x` 同义，`*p.x` 非法。
2. 存储规则：结构体按成员顺序加填充存放，共用体共享起始地址、只留一个有效成员。
3. 链表口诀：插入与删除都是先接后断，头指针一旦丢失整条链都找不回来。
4. 文件三问：用什么模式打开、位置指针现在在哪、有没有 fclose 刷新缓冲区。
