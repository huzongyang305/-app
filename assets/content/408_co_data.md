## 核心概念定义

| 术语 | 操作性定义 | 常见边界与风险 |
| --- | --- | --- |
| 原码 | 最高位为符号位，其余为数值位的绝对值。 | 易错：0 有两种表示（+0 和 -0）；不能直接用于加减运算。 |
| 反码 | 正数的反码等于原码；负数的反码符号位不变，其余取反。 | 易错：0 仍有两种表示；主要用于补码的中间步骤。 |
| 补码 | 正数的补码等于原码；负数的补码等于反码加 1。 | 易错：0 只有一种表示；可直接用于加减运算，简化硬件设计。 |
| 浮点数 | 由阶码和尾数组成，表示形如 N = M × r^E 的数。 | 易错：IEEE 754 单精度 32 位（1 位符号 + 8 位阶码 + 23 位尾数）。 |
| 溢出 | 运算结果超出机器所能表示的范围。 | 易错：双符号位法（模 4 补码）可直接判断溢出，单符号位需结合进位。 |

## 原理与运行机制

### 机制总览

**教材衔接：进制转换**

| 转换类型 | 方法 |
| --- | --- |
| 十进制→二进制 | 整数部分除 2 取余，小数部分乘 2 取整 |
| 二进制→八进制 | 每 3 位一组，从右向左分组 |
| 二进制→十六进制 | 每 4 位一组，从右向左分组 |

**教材衔接：进制转换详细示例**

十进制整数 156 转二进制（除 2 取余法）：
- 156 ÷ 2 = 78 余 0
- 78 ÷ 2 = 39 余 0
- 39 ÷ 2 = 19 余 1
- 19 ÷ 2 = 9 余 1
- 9 ÷ 2 = 4 余 1
- 4 ÷ 2 = 2 余 0
- 2 ÷ 2 = 1 余 0
- 1 ÷ 2 = 0 余 1
- 从下往上读取余数：156 = (10011100)₂

十进制小数 0.625 转二进制（乘 2 取整法）：
- 0.625 × 2 = 1.25，取整 1
- 0.25 × 2 = 0.5，取整 0
- 0.5 × 2 = 1.0，取整 1
- 从上往下读取整数：0.625 = (0.101)₂

注意：并非所有十进制小数都能精确转换为有限位二进制小数，例如 0.1 的二进制表示是无限循环小数。

**教材衔接：补码运算**

- 加法：[A + B]补 = [A]补 + [B]补（mod 2^(n+1)）
- 减法：[A - B]补 = [A]补 + [-B]补（mod 2^(n+1)）
- 溢出判断：双符号位法，结果的两个符号位不同则溢出（01 为正溢，10 为负溢）。

**教材衔接：IEEE 754 单精度浮点数**

| 字段 | 位数 | 说明 |
| --- | --- | --- |
| 符号位 S | 1 | 0 正，1 负 |
| 阶码 E | 8 | 移码表示，偏移值 127 |
| 尾数 M | 23 | 隐藏最高位 1，实际 24 位 |

计算公式：(-1)^S × 1.M × 2^(E-127)

**教材衔接：IEEE 754 双精度浮点数**

| 字段 | 位数 | 说明 |
| --- | --- | --- |
| 符号位 S | 1 | 0 正，1 负 |
| 阶码 E | 11 | 移码表示，偏移值 1023 |
| 尾数 M | 52 | 隐藏最高位 1，实际 53 位 |

计算公式：(-1)^S × 1.M × 2^(E-1023)。双精度提供约 15-17 位十进制有效数字，表示范围约为 ±1.7×10⁻³⁰⁸ 到 ±1.8×10³⁰⁸。

**教材衔接：原码、反码、补码的转换关系**

以 8 位机器字长为例，真值 x = -5：
- 原码：1000 0101（最高位符号位 1 表示负，其余为绝对值 5 = 000 0101）
- 反码：1111 1010（符号位不变，其余各位取反）
- 补码：1111 1011（反码末位加 1）

正数的原码、反码、补码相同。补码的核心优势在于将减法统一为加法运算，使得 CPU 只需设计加法器即可完成加减法，大幅简化硬件电路。

**教材衔接：溢出判断方法对比**

| 方法 | 原理 | 适用场景 |
| --- | --- | --- |
| 双符号位法（模 4 补码） | 用两位表示符号，00 为正，11 为负，01 正溢，10 负溢 | 最直接可靠，推荐用于考试 |
| 单符号位+进位法 | 符号位进位 Cs 与最高数值位进位 Cp 异或：Cs⊕Cp=1 则溢出 | 硬件实现常用 |
| 逻辑判断法 | 正+正→负 或 负+负→正 则溢出 | 概念理解用 |

注意：只有同号数相加才可能溢出。正数加负数、负数加正数不会溢出。

**教材衔接：溢出判断详细示例**

例 1：+65 + +64（8 位补码，范围 [-128, 127]）

```text
  0100 0001（+65）
+ 0100 0000（+64）
= 1000 0001

符号位进位 Cs = 0（最高数值位未向符号位进位）
最高数值位进位 Cp = 1（次高位向最高数值位有进位）
Cs ⊕ Cp = 0 ⊕ 1 = 1 → 溢出
两操作数为正，结果为负 → 正溢出
```

例 2：-65 + -64（8 位补码）

```text
[-65]补 = 1011 1111
[-64]补 = 1100 0000

  1011 1111
+ 1100 0000
= (1) 0111 1111  ← 丢弃最高位进位

Cs = 1（有进位输出）
Cp = 0（最高数值位无进位）
Cs ⊕ Cp = 1 → 溢出
两操作数为负，结果为正 → 负溢出
```

例 3：+30 + +20（无溢出情况）

```text
  0001 1110（+30）
+ 0001 0100（+20）
= 0011 0010

Cs = 0, Cp = 0
Cs ⊕ Cp = 0 → 无溢出
结果 0011 0010 = +50 ✓
```

## 典型应用场景

| 场景 | 典型输入或前提 | 期望产物 |
| --- | --- | --- |
| 补码加减运算 | 输入两个 8 位补码 | 输出结果补码与溢出标志 |
| 浮点数表示 | 输入十进制小数 | 输出 IEEE 754 单精度编码 |
| 溢出检测 | 输入两个同号数相加 | 判断是否溢出及溢出类型 |

- **补码运算中的溢出陷阱**：典型现象是用单符号位判断时漏检溢出。例如 8 位补码 0100 0000（+64）加 0011 1111（+63）= 0111 1111（+127），看似正常但实际 +64+63=+127 恰好未溢出。而 0100 0001（+65）+ 0100 0000（+64）= 1000 0001，符号位变为 10 表示负溢。正确做法是使用双符号位法，将数值扩展为两位符号位后再进行运算。
- **浮点数精度丢失**：典型现象是十进制小数 0.1 无法精确表示为二进制浮点数。IEEE 754 尾数位数有限，0.1 的二进制表示是无限循环小数 0.0001100110011...，截断后产生误差。在需要精确计算的场景（如金融）中应使用定点数或 BCD 编码。
- **进制转换中的分组方向**：典型现象是二进制转八/十六进制时分组方向搞反。正确做法是从小数点向两侧分组：整数部分从右向左，小数部分从左向右。不足位数时在两端补零。

### 最小验证场景

- 准备：保留 `补码计算` 示例的原始输入，先记录 `5 - 3` 的基线输出和完整运算步骤。
- 观察：先核对调用了 `补码加法`，再改变一个与 `操作数符号` 相关的条件（如改为两个负数相加）。
- 判定：新结果与 `补码运算` 的基线不同不等于错误；只有当差异破坏了 `补码` 的定义或错误表中的约束（如溢出未检出），才判定为失败。

### 选择与边界

- 使用 `8 位补码` 时，表示范围为 [-128, 127]；超出此范围将产生溢出，需扩展字长或采用多精度运算。
- 使用 `IEEE 754 单精度` 时，有效数字约 7 位十进制；需要更高精度时应改用双精度（64 位）或定点数方案。
- 使用 `进制转换` 时，整数部分和小数部分的转换方向相反，分组起点为小数点位置。

**教材衔接：补码乘法简介**

补码乘法比加减法复杂，常用 Booth 算法实现：

Booth 算法核心思想：
- 将乘数按位分组，根据相邻位的组合决定操作
- 00 或 11：右移一位
- 01：加被乘数，右移一位
- 10：减被乘数，右移一位

8 位 Booth 乘法示例（5 × 3）：
```text
被乘数 5 = 0000 0101
乘数 3 = 0000 0011
附加位 = 0

步骤：
1. 乘数末两位 10，减被乘数：0000 0101 → 1111 1011
2. 算术右移：1111 1101 1
3. 末两位 11，右移：1111 1110 1
4. 末两位 01，加被乘数：1111 1110 1 + 0000 0101 = 0000 0100 1
5. 算术右移：0000 0010 0
结果：0000 1111 = 15 ✓
```

注意：Booth 算法可处理有符号数乘法，是 CPU 乘法器的基础算法。

**教材衔接：IEEE 754 编码示例**

```text
例：将 6.75 转换为 IEEE 754 单精度
6.75 = 110.11 = 1.1011 × 2^2
S = 0（正数）
E = 2 + 127 = 129 = 1000 0001
M = 1011 0000 0000 0000 0000 000（隐藏最高位 1）
结果：0 10000001 10110000000000000000000
十六进制：0x40D80000
```

**教材衔接：IEEE 754 特殊值**

| 类型 | 阶码 E | 尾数 M | 含义 |
| --- | --- | --- | --- |
| 规格化数 | 1~254 | 任意 | 正常浮点数，值为 (-1)^S × 1.M × 2^(E-127) |
| 非规格化数 | 0 | 非零 | 接近零的小数，值为 (-1)^S × 0.M × 2^(-126) |
| 零 | 0 | 0 | +0 或 -0（取决于符号位） |
| 无穷大 | 255 | 0 | +∞ 或 -∞，表示溢出结果 |
| NaN | 255 | 非零 | 非数，表示 0/0、√(-1) 等未定义运算 |

**教材衔接：IEEE 754 解码示例**

```text
例：将单精度浮点数 0xC2F00000 转换为十进制
二进制：1 10000101 11100000000000000000000
S = 1（负数）
E = 10000101 = 133，实际指数 e = 133 - 127 = 6
M = 11100000000000000000000，隐藏位 1，尾数 = 1.111
值 = -1.111 × 2^6 = -1111000 = -120
验证：0xC2F00000 = -120.0 ✓
```

**教材衔接：浮点数运算注意事项**

浮点数运算的常见陷阱：

1. **精度丢失**：0.1 + 0.2 ≠ 0.3（实际为 0.30000000000000004）
   - 原因：0.1 和 0.2 无法精确表示为二进制浮点数
   - 解决：使用定点数或比较时用 epsilon（如 abs(a-b) < 1e-6）

2. **溢出处理**：两个大数相乘可能超出表示范围
   - 单精度最大值约 3.4 × 10^38
   - 溢出结果：正溢出为 +∞，负溢出为 -∞

3. **特殊值比较**：NaN ≠ NaN（任何与 NaN 的比较都返回 false）
   - 判断 NaN：使用 isNaN() 函数或 x != x

4. **舍入误差累积**：多次运算后误差可能放大
   - 解决：使用高精度类型（如 double 代替 float）或重新设计算法

5. **下溢问题**：非常接近零的数可能变为非规格化数或零
   - 单精度最小正规格化数约 1.18 × 10^-38
   - 非规格化数可表示更小的数，但精度降低

**考试技巧**：遇到浮点数比较题时，优先考虑精度问题；遇到编码题时，按步骤计算 S、E、M 三位。

## 时间/空间复杂度或性能分析

**性能关注点（数据运算）**：运算速度与精度是主要指标。

**测量方法**：
- 补码加减法：一次加法运算，时间 O(1)。
- 浮点数运算：需对阶、尾数运算、规格化、舍入，时间 O(1) 但步骤多。

**定点数 vs 浮点数对比**：

| 维度 | 定点数 | 浮点数 |
| --- | --- | --- |
| 表示范围 | 固定，如 8 位整数 [-128, 127] | 巨大，单精度约 ±10^38 |
| 精度 | 均匀分布，每档间隔相等 | 非均匀，越接近零精度越高 |
| 运算速度 | 快，硬件简单 | 慢，需复杂对阶和规格化 |
| 适用场景 | 金融、嵌入式、DSP | 科学计算、图形、AI |
| 误差特性 | 无舍入误差（范围内） | 有舍入误差，累积可能严重 |

**浮点数运算步骤**（以加法为例）：
1. **对阶**：小阶向大阶看齐，尾数右移，低位可能丢失
2. **尾数求和**：对齐后的尾数按补码加法运算
3. **规格化**：左规（尾数左移，阶码减）或右规（尾数右移，阶码加）
4. **舍入**：按 IEEE 754 规定的舍入模式（就近舍入、截断等）
5. **溢出判断**：阶码上溢→无穷大，阶码下溢→机器零

## 常见误区与易错点

| 容易写错的做法 | 实际现象 | 原因与正确做法 |
| --- | --- | --- |
| 混淆原码与补码 | 加减运算结果错误 | 补码可直接用于加减，原码不行 |
| IEEE 754 阶码未加偏移 | 表示错误 | 单精度偏移 127，双精度偏移 1023 |
| 溢出判断用单符号位 | 误判溢出 | 双符号位法更直观可靠 |
| 浮点数尾数隐藏位忘记 | 精度丢失 | IEEE 754 尾数隐藏最高位 1 |
| 负数补码计算错误 | 结果符号错误 | 负数补码 = 反码 + 1，不是原码取反 |
| 进制转换分组方向反 | 结果错误 | 整数从右向左，小数从左向右 |
| 溢出判断混淆 Cs 和 Cp | 误判溢出类型 | Cs 是符号位进位，Cp 是最高数值位进位 |

**教材衔接：补码运算规则总结**

8 位补码运算规则：
- 表示范围：[-128, 127]
- 正数补码 = 原码
- 负数补码 = 反码 + 1（符号位不变，其余取反后加 1）
- 特殊值：1000 0000 表示 -128（无原码和反码）
- 加法：[A+B]补 = [A]补 + [B]补（mod 256）
- 减法：[A-B]补 = [A]补 + [-B]补（mod 256）

**教材衔接：IEEE 754 特殊值详解**

| 类型 | 阶码 E | 尾数 M | 含义 |
| --- | --- | --- | --- |
| 规格化数 | 1~254 | 任意 | (-1)^S × 1.M × 2^(E-127) |
| 非规格化数 | 0 | 非零 | (-1)^S × 0.M × 2^(-126)，用于表示接近零的数 |
| 零 | 0 | 0 | +0（S=0）或 -0（S=1） |
| 无穷大 | 255 | 0 | +∞（S=0）或 -∞（S=1），表示溢出 |
| NaN | 255 | 非零 | 非数，表示 0/0、√(-1) 等未定义运算 |

非规格化数的作用：填补规格化数无法表示的接近零的区域，实现"渐进下溢"。

## 自测题与参考答案

### 自测 1

求 [-128]补（8 位）。

**参考答案**：-128 的 8 位补码为 1000 0000。注意 -128 没有原码和反码表示（8 位原码范围 [-127, 127]），但补码可以表示 -128。

### 自测 2

将十进制数 -0.6875 转换为 IEEE 754 单精度浮点数。

**参考答案**：
- -0.6875 = -0.1011 = -1.011 × 2^(-1)
- S = 1（负数）
- E = -1 + 127 = 126 = 0111 1110
- M = 0110 0000 0000 0000 0000 000
- 结果：1 01111110 01100000000000000000000
- 十六进制：0xBF300000

### 自测 3

用双符号位法判断 0100 + 0100 是否溢出。

**参考答案**：
- 0100 的双符号位补码为 00 0100
- 00 0100 + 00 0100 = 00 1000
- 双符号位为 00，相同，无溢出。结果为 +8。

### 自测 4

为什么计算机内部用补码而不是原码进行加减运算？

**参考答案**：
1. 补码可以将减法转化为加法，简化硬件设计（只需加法器）。
2. 补码中 0 只有一种表示（原码有 +0 和 -0），避免歧义。
3. 补码的符号位可以直接参与运算，不需要单独处理。

### 自测 5

IEEE 754 单精度浮点数的表示范围是多少？

**参考答案**：
- 阶码 E 范围：1~254（0 和 255 用于表示特殊值）
- 实际指数 e = E - 127，范围：-126~127
- 尾数 M 范围：1.0~1.999...（隐藏最高位 1）
- 表示范围：±1.0 × 2^(-126) ~ ±1.999... × 2^127
- 约 ±1.18 × 10^(-38) ~ ±3.4 × 10^38

## 术语速查

| 术语 | 一句话说明 |
| --- | --- |
| 原码 | 最高位为符号位，其余为数值位的绝对值。 |
| 反码 | 正数等于原码；负数符号位不变，其余取反。 |
| 补码 | 正数等于原码；负数等于反码加 1。 |
| 浮点数 | 由阶码和尾数组成，表示形如 N = M × r^E 的数。 |
| IEEE 754 | 浮点数表示标准，单精度 32 位，双精度 64 位。 |
| 溢出 | 运算结果超出机器字长所能表示的范围。 |
| 规格化 | 尾数最高位为 1 的浮点数表示形式。 |
