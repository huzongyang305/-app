## 核心概念定义

先认识几个名词，后面会反复遇到：

| 术语 | 一句话说明 |
| --- | --- |
| input | Python 内置函数，从键盘读取一行文字，返回值永远是字符串。 |
| 类型转换 | 用 `int()` 或 `float()` 把字符串转成数字，才能做数学运算。 |
| f-string | 格式化字符串，用 `f"..."` 在引号里直接嵌入变量，写法最简洁。 |
| strip | 字符串方法，去掉首尾的空格和换行符，避免用户多按空格导致判断出错。 |
| 标准输入输出 | 程序跟终端交换数据的通道：`input()` 读入，`print()` 输出。 |
| print 参数 | `print()` 还能带 `sep`（多个值之间塞什么）和 `end`（这一行末尾补什么），默认分别是空格和换行。 |
| 哨兵值 | 一个约定好的输入（比如直接回车）代表"采集结束"，让重复读取知道什么时候停。 |
| 输入守护 | 转换之前先判断"能不能转"，例如 `isdigit()`，避免当场报 `ValueError`。 |

## 原理与运行机制

### 你的程序怎么跟用户"对话"

```text
程序打印提示文字（print）
    ↓
用户在键盘输入内容，按回车
    ↓
input() 把输入的文字作为字符串返回
    ↓
程序处理数据（转换类型、计算）
    ↓
程序输出结果（print）
```

整个过程就像填表：程序问你一个问题（print 提示），你在表格里填答案（input 输入），程序拿到答案后处理并告诉你结果（print 输出）。

### input() 返回的永远是字符串

```python
age = input("请输入年龄：")
print(type(age))  # 输出：<class 'str'>
```

不管你输入的是 `18` 还是 `abc`，`input()` 都把它当字符串返回。这意味着你不能直接拿它做数学运算：

```python
age = input("年龄：")
print(age + 1)  # 报错！TypeError: can only concatenate str (not "int") to str
```

### 类型转换：把字符串变成数字

```python
age = input("年龄：")
age_num = int(age)  # 把字符串转成整数
print(age_num + 1)  # 现在可以做数学运算了
```

用 `int()` 把字符串转成整数，用 `float()` 转成浮点数。如果用户输入的不是数字，会报 `ValueError`：

```python
age = int(input("年龄："))  # 如果输入 abc，这里会报错
```

### 用 strip() 清理输入

```python
name = input("名字：").strip()
```

用户有时候会多按空格，比如输入 `" 小明  "`。`strip()` 去掉首尾的空白字符，得到 `"小明"`。这在判断用户是否输入了内容时特别有用：

```python
name = input("名字：").strip()
if not name:
    name = "匿名用户"
```

### f-string：最方便的格式化方式

```python
name = "小明"
age = 18
print(f"你好，{name}，你今年 {age} 岁")
```

在引号前加 `f`，就可以在引号里用 `{变量名}` 嵌入变量。这是 Python 3.6+ 推荐的格式化方式，写法最直观。

还能在 `{}` 里做简单的格式化：

```python
price = 99.5
print(f"价格：{price:.2f} 元")  # 保留 2 位小数，输出：价格：99.50 元
```

### print 是怎么把内容送到屏幕上的

`print()` 并不是真的"打印"，而是往标准输出这条通道里写字。落笔前它做两件事：先用 `sep` 指定的分隔符把你给的多个值粘成一行，再在末尾补上 `end` 指定的字符。

```python
print("总价", 12.5, "元")            # 默认 sep 是空格，end 是换行
print("总价", 12.5, "元", sep="", end="。\n")
```

两行输出分别是 `总价 12.5 元` 和 `总价12.5元。`。生活化的类比是寄快递：`sep` 决定两件东西之间塞不塞泡沫，`end` 决定箱子封口贴什么。打小票时你多半希望 `sep=""`，把空格全部交给 f-string 控制，列才对得齐。

循环里 `print` 完程序却半天没动静，通常是缓冲区还没交出去，给那一句加 `flush=True` 就能强制立刻显示，适合"处理中……"这类进度提示。

### 一次 input() 到底吃掉了什么

`input()` 只取到回车为止的内容，并且把结尾的换行符丢掉，所以它后面再 `print` 不会莫名多出一行空白。用户什么都不填直接回车，返回值是空字符串：

```python
line = input("数量：")   # 用户直接按回车
print(repr(line))        # 输出 ''，repr 会让空字符串现出原形
```

拿到空串就 `int()` 会当场报 `ValueError: invalid literal for int() with base 10: ''`。另外，Windows 终端按 Ctrl+Z、macOS/Linux 按 Ctrl+D 代表"输入到此为止"，此时 `input()` 不再等待，而是抛出 `EOFError`——它多半说明你是用文件重定向喂数据的，行数比程序要的少。

### 先看能不能转，再动手转

```python
raw = input("年龄：").strip()
if raw.isdigit():
    print(f"明年你 {int(raw) + 1} 岁")
else:
    print("年龄请写成数字，例如 18")
```

`isdigit()` 只认纯数字，`3.5` 和 `-1` 都会被它拦下。要允许小数，可以先做粗判断再转换：

```python
raw = input("价格：").strip()
if raw.replace(".", "", 1).isdigit() and raw != ".":
    print(f"{float(raw) * 1.13:.2f} 元（含税）")
```

这种"先问一句能不能转"的写法在异常处理还没学到时最实用；等你接触 `try/except`，同样的判断会换成兜底的写法，但"先确认再转换"的次序不会变。

### f-string 的格子里能放什么

花括号里不止能写变量名，还能放一个能算出值的表达式，甚至是条件表达式：

```python
price, count = 12.5, 3
print(f"{price * count:.2f}")      # 先算再格式化 → 37.50
print(f"{price * count:>10.2f}")   # 右对齐，总宽 10 个字符
name = "  小明  "
print(f"{name!r}")                 # 按原始形式显示 → '  小明  '，藏起来的空格一眼就看见
print(f"{name=}")                  # Python 3.8+ 的调试写法 → name='  小明  '
```

做表格输出的关键是"宽度在前、小数在后"：`:<10` 表示左对齐占 10 格，`>10.2f` 表示右对齐占 10 格并保留两位小数。

## 典型应用场景

`input()` 和 `print()` 组合起来能做很多事：

- **交互式小工具**：计算器、单位转换器、密码生成器
- **问卷调查**：收集用户信息并保存到文件
- **命令行游戏**：猜数字、文字冒险游戏
- **数据录入**：批量输入数据并处理

这些都不需要复杂的图形界面，在终端就能跑。

### 一个实际的小例子

让用户输入名字，打印欢迎信息：

```python
name = input("名字：").strip() or "world"
print(f"hello, {name}")
```

逐行解释：
- `input("名字：")`：打印提示文字，等待用户输入
- `.strip()`：去掉首尾空白
- `or "world"`：如果用户直接按回车（输入为空），就用 `"world"` 作为默认值
- `f"hello, {name}"`：把变量 `name` 嵌入字符串

运行效果：

```text
名字：小明
hello, 小明
```

### 场景一：把零散输入整理成一张对齐的小票

收银台要打印"品名、数量、小计"三列。人手敲出来的宽度千奇百怪，所以读进来之后要做三件事：`strip()` 去空白、转成数字、用 f-string 定宽对齐。

```python
item = input("品名：").strip()
count = int(input("数量："))
price = float(input("单价："))
line = f"{item:<10}{count:>4}{price * count:>10.2f}"
print(line)
print("-" * len(line))
```

三次提问分别回答 `苹果`、`3`、`2.5`，最后输出类似 `苹果         3      7.50`，紧跟一条跟表头等长的分隔线。`len(line)` 在这里的作用是让横线长度自动跟着内容走，改品名也不用重调横线。

### 场景二：连续采集，用空回车收尾

统计"今天一共记了多少笔"时你并不知道笔数，就用空回车当结束信号：

```python
records = []
while True:
    raw = input("金额（直接回车结束）：").strip()
    if not raw:
        break
    if raw.replace(".", "", 1).isdigit():
        records.append(float(raw))
    else:
        print(f"{raw} 不像金额，已跳过")

print(f"共 {len(records)} 笔，合计 {sum(records):.2f} 元")
```

`while` 和 `break` 属于后面两课的内容，先照抄跑通即可。这段真正要体会的是三件事怎么接上：`strip()` 判空当结束信号、`isdigit()` 做转换守护、f-string 一次性把汇总结果格式化出来。

### 完整示例：简单的加法计算器

```python
# 让用户输入两个数字，打印它们的和
a = input("第一个数字：")
b = input("第二个数字：")

# 转换成数字
num_a = float(a)
num_b = float(b)

# 计算并输出
result = num_a + num_b
print(f"{a} + {b} = {result}")
```

逐行解释：

- `input("第一个数字：")`：提示用户输入，返回字符串
- `float(a)`：把字符串转成浮点数（支持小数）
- `num_a + num_b`：做加法运算
- `f"{a} + {b} = {result}"`：格式化输出，`{a}` 和 `{b}` 还是原来的字符串，`{result}` 是计算结果

运行效果：

```text
第一个数字：3.5
第二个数字：2
3.5 + 2 = 5.5
```

### 渐进示例：从能跑，到不怕乱输

第一步，最小可跑，只确认"问一句、答一句、回一句"这条链路通：

```python
raw = input("输入一个整数：")
print(f"你输入的是 {raw}")
```

第二步，加上类型转换和边界守护，同时算两个结果：

```python
raw = input("输入一个整数：").strip()
if raw.isdigit():
    n = int(raw)
    parity = "偶数" if n % 2 == 0 else "奇数"
    print(f"{n} 的平方是 {n * n}，它是{parity}")
else:
    print("请只输入整数，例如 7")
```

第三步，把"读入 → 校验 → 计算 → 输出"放进循环，变成一件能反复用的小工具：

```python
total = 0
while True:
    raw = input("输入一个整数（回车结束）：").strip()
    if not raw:
        break
    if not raw.isdigit():
        continue
    n = int(raw)
    total += n
    print(f"当前累计 {total}")

print(f"一共加出 {total}")
```

三个版本的区别不在语法，而在职责分层：第一版只管收发，第二版管类型和边界，第三版管重复与汇总。自测方法是拿同一份输入 `7 abc 3` 依次跑三个版本，看它们各自在哪一步停下、给你什么提示。

## 时间/空间复杂度或性能分析

本课的代码只是简单的输入输出，暂时不需要关心性能。

等你写到处理大量输入或文件时，再回来关注：
- **I/O 性能**：`input()` 是阻塞的，会等用户输入，不适合高频调用
- **内存**：一次性读入大量数据会占内存，可以用生成器逐行处理

现在记住一点就好：**先让程序能跑，再考虑优化。**

### 输入侧：一次读一行才是常态

`input()` 的耗时几乎全部花在"等人"上，跟你写了几行代码没什么关系，所以它不是性能瓶颈，而是流程瓶颈。真正会失控的是"一口气读太多"：等你开始处理文件里的十万行数据时，一行一行地处理，内存里只留当前这一行；先把全部内容读成一个大字符串再切分，内存就跟着数据规模一起涨。

### 输出侧：省掉多余的换行和强制刷新

`print` 的成本集中在两处——字符串拼接和往终端写。循环里逐条 `print` 十万次是可以接受的，但每条都带 `flush=True` 会明显变慢，因为你在强迫缓冲区每次立刻交出去。批量输出更划算的写法是把各行先放进列表，最后 `print("\n".join(lines))` 一次写完。

### 让结果可以被复现

谈性能之前，得先保证两次跑的是同一份数据。把输入写进文件重定向给程序，就不需要人坐在键盘前逐条敲：

```bash
python greet.py < names.txt
```

`names.txt` 一行一个名字，`input()` 就一行一个地取，取完时抛 `EOFError`。顺手还能把"乱输"也写进同一个文件：一行 `18`、一行 `abc`、一行空行——程序到底崩没崩，跑一次就有结论，这也是本课自测题反复强调"覆盖边界输入"的具体做法。

## 常见误区与易错点

| 容易犯的错误 | 会出现什么 | 怎么修 |
| --- | --- | --- |
| 直接用 `input()` 的结果做数学运算 | 报 `TypeError` | 先用 `int()` 或 `float()` 转换 |
| 用户输入非数字，转换时报错 | 报 `ValueError` | 用 `try/except` 捕获异常（后面会学） |
| 忘记 `strip()`，用户多按空格导致判断出错 | 条件判断不符合预期 | 在 `input()` 后加 `.strip()` |
| 用 `+` 拼接字符串和数字 | 报 `TypeError` | 用 f-string 或 `str()` 转换 |
| 用旧式格式化 `%` 或 `.format()` | 代码冗长，不易读 | 改用 f-string（Python 3.6+） |
| 拿 `input()` 的结果直接和数字比较 | `"18" == 18` 永远为 `False`，还不报错 | 先 `int()` 再比较，或把 `18` 写成 `"18"` |
| 用户直接回车就立刻转换 | 报 `ValueError: invalid literal for int() with base 10: ''` | 转换前 `strip()` 判空，空值走默认值 |
| 用 `eval(input())` 图省事支持算式 | 用户输什么就被执行什么，等于把机器交出去 | 只用 `int()`、`float()` 做显式转换 |
| 提示语写在单独的 `print()` 里 | 光标跑到下一行，输入和提示错位 | 提示作为 `input()` 的参数传入 |

### 遇到报错怎么办

1. **读报错信息**——`TypeError` 是类型问题，`ValueError` 是转换失败
2. **检查类型**——用 `type()` 看变量是什么类型
3. **转换类型**——用 `int()`、`float()` 或 `str()` 转换
4. **处理异常**——用 `try/except` 捕获转换失败的情况

### 现场：数字输对了，判断却不成立

**症状**：`if input("年龄：") == 18:` 永远走不通，程序看起来"忽略"了你的输入。

**根因与修复**：`input()` 返回的是 `str`，而 `"18" == 18` 在 Python 里是 `False`，并不报错。这种"静默不相等"比崩溃更难查。把返回值先转成 `int` 再比较，或者反过来把 `18` 写成 `"18"`——后者只在你确认用户不会多打空格时才可靠。

### 现场：`strip()` 写成了 `strip`

**症状**：`name = input("名字：").strip or "world"` 跑通了，但输入三个空格时 `name` 仍然是那串空格。

**根因与修复**：漏了括号，`.strip` 取到的是方法对象本身，而方法对象永远"为真"，`or` 后面的默认值就再也不会生效。加上括号写成 `.strip()` 才是真正调用。本课自测里那条 `name = input("名字：").strip or "world"` 问的就是这个区别。

## 与其他知识点的关系

本课学到的东西会被后面每一课反复用到：

- **下一课《Python 条件判断》**：你会学到 `if/else` 让代码做选择，结合 `input()` 可以做交互式程序
- **《Python 循环入门》**：用循环重复接收输入，处理批量数据
- **《Python 列表与字典》**：把用户输入的数据存到列表或字典里
- **《Python 字符串处理》**：`strip()` 只是清洗的第一步，`split()`、`replace()`、`join()` 会接手更复杂的整理工作，本课的小票对齐就是靠它们才不用手敲空格
- **《异常处理》**：现在你用 `isdigit()` 提前挡掉的转换失败，那时会换成 `try/except` 兜底；两种写法都能用，区别是"先问"还是"先做再补救"
- **终端与操作系统里的标准输入输出**：`input()` 和 `print()` 只是 Python 给 stdin/stdout 这两个通道起的门面名字，管道、重定向、缓冲区那些行为在后面接触文件读写时会原封不动地再遇到一次

现在你只需要记住一件事：**`input()` 接收输入返回字符串，转成数字才能运算，f-string 让输出更美观。**

## 术语速查

| 术语 | 一句话说明 |
| --- | --- |
| `input` | 从键盘读取一行文字，返回字符串 |
| `类型转换` | 用 `int()` 或 `float()` 把字符串转成数字 |
| `f-string` | 用 `f"..."` 在字符串里嵌入变量 |
| `strip` | 去掉字符串首尾的空白字符 |
| `标准输入输出` | `input()` 读入，`print()` 输出 |
| `sep 与 end` | `print` 的两个参数：多个值之间塞什么、这一行末尾补什么 |
| `EOFError` | 输入被用完（Ctrl+Z 或 Ctrl+D）时 `input()` 抛出的错误 |
| `isdigit` | 字符串方法，判断是否全是数字字符，转换前先问它一句 |
| `定宽输出` | f-string 里用 `:>10.2f`、`:<10` 指定宽度与对齐，让多行结果排成列 |

## 考点精讲

`Python 输入与输出` 的题库有 5 道题，下面逐题给出题干、正确项与判断依据：先自己作答，再核对正确项，最后回到正文对应小节复核。

### 考点 1：第 1 题

- **题目**：input 函数的返回值默认是什么类型？
- **正确项**：字符串 str，需要手动转换成数字才能参与算术
- **判断依据**：本题正确项是「字符串 str，需要手动转换成数字才能参与算术」。术语 input（Python 输入与输出）：从标准输入读入一行文本，返回值始终是字符串，本题取「字符串 str，需要手动转换成数字才能参与算术」这条。易错点是直接用 `input()` 的结果做数学运算，会造成报 `TypeError`，改法是先用 `int()` 或 `float()` 转换。

### 考点 2：第 2 题

- **题目**：在 name = input("名字：").strip or "world" 中，strip 的作用是？
- **正确项**：去掉输入首尾的空白字符，避免误判为空输入
- **判断依据**：本题正确项是「去掉输入首尾的空白字符，避免误判为空输入」。术语 input（Python 输入与输出）：从标准输入读入一行文本，返回值始终是字符串，本题取「去掉输入首尾的空白字符，避免误判为空输入」这条。易错点是用户输入非数字，转换时报错，会造成报 `ValueError`，改法是用 `try/except` 捕获异常（后面会学）。

### 考点 3：第 3 题

- **题目**：围绕“Python 输入与输出”中的 Python 输入与输出、Python、入门练习，下列哪两项是本课强调的实践判断？
- **正确项**：学习 Python 输入与输出 时要同时说明输入、输出和失败路径，不能只看正常流程；验证 Python 时要固定版本并覆盖边界输入，结论才可复现
- **判断依据**：按《Python 输入与输出》的正文口径，本题要同时选中「学习 Python 输入与输出 时要同时说明输入、输出和失败路径，不能只看正常流程」、「验证 Python 时要固定版本并覆盖边界输入，结论才可复现」，漏掉任一项都算没答全。术语 input（Python 输入与输出）：从标准输入读入一行文本，返回值始终是字符串。易错点是忘记 `strip()`，用户多按空格导致判断出错，会造成条件判断不符合预期，改法是在 `input()` 后加 `.strip()`。

### 考点 4：第 4 题

- **题目**：下面这段 `python` 代码来自 `Python 输入与输出`。课程主线是读取用户输入、转换类型并格式化输出。代码与 `input` 有关。哪一项是代码里真实出现的内容？
- **正确项**：出现字面量 `hello, {name}`
- **判断依据**：本题正确项是「出现字面量 `hello, {name}`」。术语 input（Python 输入与输出）：从标准输入读入一行文本，返回值始终是字符串，本题取「出现字面量 `hello, {name}`」这条。易错点是用 `+` 拼接字符串和数字，会造成报 `TypeError`，改法是用 f-string 或 `str()` 转换。本题干扰项「出现字面量 `utf-8`」不成立：展示代码里找不到 `utf-8`。

- **题目**：填空：补齐下面这段术语说明中的空缺。课程 `读取用户输入、转换类型并格式化输出。`，这段说明是：`____`：从标准输入读入一行文本，返回值始终是字符串。空缺处应填哪个术语？
