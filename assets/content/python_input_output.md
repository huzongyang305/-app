## 学习目标

- 先认识「Python 输入与输出」需要的工具、输入和输出。
- 按步骤运行最小示例，并记录结果与错误。

## 前置知识

- 会进行基本的文件或命令行操作。
- 不需要预先掌握「Python」的高级知识。

## 一句话入门

读取用户输入、转换类型并格式化输出。

## 最小示例

```python
value = 2 + 3
print(f"result={value}")
```

## 预期输出

```text
result=5
```

## 常见错误

- 忘记转换 input() 返回的字符串，直接参与算术会抛 TypeError。
- 复制命令时遗漏空格、引号或必要参数。

## 动手练习

1. 原样运行最小示例，保存命令和输出。
2. 把数字 2 改成 10，预测并验证新结果。
3. 制造一个错误输入，写出错误信息和修复方法。

## 本课小结

- 入门阶段先保证能运行、能观察、能解释，再追求复杂功能。
- 每次只改一个变量，记录预测与实际结果。
- 遇到错误先看第一条错误信息，再回到最小示例。
