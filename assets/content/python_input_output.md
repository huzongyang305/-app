## 核心概念定义

先认识几个名词，后面会反复遇到：

| 术语 | 一句话说明 |
| --- | --- |
| input | Python 内置函数，从键盘读取一行文字，返回值永远是字符串。 |
| 类型转换 | 用 `int()` 或 `float()` 把字符串转成数字，才能做数学运算。 |
| f-string | 格式化字符串，用 `f"..."` 在引号里直接嵌入变量，写法最简洁。 |
| strip | 字符串方法，去掉首尾的空格和换行符，避免用户多按空格导致判断出错。 |
| 标准输入输出 | 程序跟终端交换数据的通道：`input()` 读入，`print()` 输出。 |

## 原理与运行机制

### 你的程序怎么跟用户"对话"

```text
程序打印提示文字（print）
    ↓
用户在键盘输入内容，按回车
    ↓
input() 把输入的文字作为字符串返回
    ↓
程序处理数据（转换类型、计算）
    ↓
程序输出结果（print）
```

整个过程就像填表：程序问你一个问题（print 提示），你在表格里填答案（input 输入），程序拿到答案后处理并告诉你结果（print 输出）。

### input() 返回的永远是字符串

```python
age = input("请输入年龄：")
print(type(age))  # 输出：<class 'str'>
```

不管你输入的是 `18` 还是 `abc`，`input()` 都把它当字符串返回。这意味着你不能直接拿它做数学运算：

```python
age = input("年龄：")
print(age + 1)  # 报错！TypeError: can only concatenate str (not "int") to str
```

### 类型转换：把字符串变成数字

```python
age = input("年龄：")
age_num = int(age)  # 把字符串转成整数
print(age_num + 1)  # 现在可以做数学运算了
```

用 `int()` 把字符串转成整数，用 `float()` 转成浮点数。如果用户输入的不是数字，会报 `ValueError`：

```python
age = int(input("年龄："))  # 如果输入 abc，这里会报错
```

### 用 strip() 清理输入

```python
name = input("名字：").strip()
```

用户有时候会多按空格，比如输入 `" 小明  "`。`strip()` 去掉首尾的空白字符，得到 `"小明"`。这在判断用户是否输入了内容时特别有用：

```python
name = input("名字：").strip()
if not name:
    name = "匿名用户"
```

### f-string：最方便的格式化方式

```python
name = "小明"
age = 18
print(f"你好，{name}，你今年 {age} 岁")
```

在引号前加 `f`，就可以在引号里用 `{变量名}` 嵌入变量。这是 Python 3.6+ 推荐的格式化方式，写法最直观。

还能在 `{}` 里做简单的格式化：

```python
price = 99.5
print(f"价格：{price:.2f} 元")  # 保留 2 位小数，输出：价格：99.50 元
```

## 典型应用场景

`input()` 和 `print()` 组合起来能做很多事：

- **交互式小工具**：计算器、单位转换器、密码生成器
- **问卷调查**：收集用户信息并保存到文件
- **命令行游戏**：猜数字、文字冒险游戏
- **数据录入**：批量输入数据并处理

这些都不需要复杂的图形界面，在终端就能跑。

### 一个实际的小例子

让用户输入名字，打印欢迎信息：

```python
name = input("名字：").strip() or "world"
print(f"hello, {name}")
```

逐行解释：
- `input("名字：")`：打印提示文字，等待用户输入
- `.strip()`：去掉首尾空白
- `or "world"`：如果用户直接按回车（输入为空），就用 `"world"` 作为默认值
- `f"hello, {name}"`：把变量 `name` 嵌入字符串

运行效果：

```text
名字：小明
hello, 小明
```

### 完整示例：简单的加法计算器

```python
# 让用户输入两个数字，打印它们的和
a = input("第一个数字：")
b = input("第二个数字：")

# 转换成数字
num_a = float(a)
num_b = float(b)

# 计算并输出
result = num_a + num_b
print(f"{a} + {b} = {result}")
```

逐行解释：

- `input("第一个数字：")`：提示用户输入，返回字符串
- `float(a)`：把字符串转成浮点数（支持小数）
- `num_a + num_b`：做加法运算
- `f"{a} + {b} = {result}"`：格式化输出，`{a}` 和 `{b}` 还是原来的字符串，`{result}` 是计算结果

运行效果：

```text
第一个数字：3.5
第二个数字：2
3.5 + 2 = 5.5
```

## 时间/空间复杂度或性能分析

本课的代码只是简单的输入输出，暂时不需要关心性能。

等你写到处理大量输入或文件时，再回来关注：
- **I/O 性能**：`input()` 是阻塞的，会等用户输入，不适合高频调用
- **内存**：一次性读入大量数据会占内存，可以用生成器逐行处理

## 常见误区与易错点

| 容易犯的错误 | 会出现什么 | 怎么修 |
| --- | --- | --- |
| 直接用 `input()` 的结果做数学运算 | 报 `TypeError` | 先用 `int()` 或 `float()` 转换 |
| 用户输入非数字，转换时报错 | 报 `ValueError` | 用 `try/except` 捕获异常（后面会学） |
| 忘记 `strip()`，用户多按空格导致判断出错 | 条件判断不符合预期 | 在 `input()` 后加 `.strip()` |
| 用 `+` 拼接字符串和数字 | 报 `TypeError` | 用 f-string 或 `str()` 转换 |
| 用旧式格式化 `%` 或 `.format()` | 代码冗长，不易读 | 改用 f-string（Python 3.6+） |

### 遇到报错怎么办

1. **读报错信息**——`TypeError` 是类型问题，`ValueError` 是转换失败
2. **检查类型**——用 `type()` 看变量是什么类型
3. **转换类型**——用 `int()`、`float()` 或 `str()` 转换
4. **处理异常**——用 `try/except` 捕获转换失败的情况
