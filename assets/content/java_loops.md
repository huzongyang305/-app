## Java 基础机制速览

### JDK、JVM 与字节码

Java 源码编译成平台无关的字节码，JVM 负责加载、验证、解释和即时编译。JDK 包含编译器和工具，JRE 只包含运行环境。类加载器按委托模型加载类，`main` 方法是程序入口。理解编译期与运行期的区别，能定位“编译通过但运行时找不到类”和“类型擦除导致的行为差异”。

### 类、对象与静态成员

类是对象的模板，对象保存实例字段，方法定义行为。`static` 成员属于类而不是实例，静态方法不能直接访问实例字段。构造器初始化对象，`this` 指向当前实例，`super` 调用父类成员。封装通过访问修饰符实现，继承表达“是一个”，组合表达“有一个”；优先使用组合降低耦合。`equals`、`hashCode` 和 `toString` 要根据值语义一致地重写。

### 类型、装箱与字符串

Java 有基本类型和引用类型，泛型不能直接使用基本类型，需要装箱成包装类。自动装箱方便但会增加对象分配，比较包装类应使用 `equals` 而不是 `==`。字符串不可变，拼接会产生新对象，循环中应使用 `StringBuilder`。`final` 表示引用不可重新赋值，不代表对象内容不可变。

### 集合、泛型与函数式接口

`List`、`Set`、`Map` 是集合接口，`ArrayList`、`HashSet`、`HashMap` 是常见实现。泛型在编译期提供类型检查，运行时发生类型擦除，因此不能创建泛型数组，也不能依赖运行时泛型信息。Stream 提供声明式的筛选、映射和聚合，但要注意惰性、短路和并行流的线程安全。Lambda 和函数式接口让行为可以作为参数传递。

### 异常、资源与并发

受检异常必须在签名中声明或捕获，非受检异常通常表示编程错误。`try-with-resources` 自动关闭实现 AutoCloseable 的资源。线程共享堆内存，必须使用同步、锁、原子类或并发集合保护共享状态；线程池避免频繁创建线程，但要合理设置队列、拒绝策略和超时。虚拟线程降低了高并发 I/O 的线程成本，但不会自动消除数据竞争。

## 考点精讲：把测验题还原成判断过程

本课有 4 个判断点。先自己作答，再看「判断依据」；如果结论正确但理由不完整，回到正文对应章节补足概念。

### 考点 1：示例中 for (int i = 1; i <= 5; i++) 累加后的输出是什么？

- **正确判断**：total=15，循环累加 1 到 5 五个整数
- **判断依据**：i 依次取 1 到 5，每轮执行 total += i，循环结束时累加得到 15；i 自增到 6 后条件不成立，循环退出。输出语句在循环之外，所以只打印一行。若把条件写成 i < 5 会漏掉 5，若把 println 放进循环则会输出五行结果。
- **迁移检查**：如果给某个错误选项去掉一个限定词，它会不会变成正确？说明理由。

### 考点 2：Java 的增强 for 循环 for (int value : numbers) 适合什么场景？

- **正确判断**：依次访问数组或集合中的每个元素，不需要下标
- **判断依据**：增强 for 语法把遍历细节交给编译器，代码更简洁，适合只读访问全部元素；但它不提供下标，遍历时删除集合元素可能抛出 ConcurrentModificationException，需要改用迭代器或 removeIf。若需要控制方向或跳过元素，应使用普通 for 循环或流式操作。
- **迁移检查**：遮住选项，只根据定义复述一次答案，再回来看哪个选项与复述一致。

### 考点 3：在循环中，break 与 continue 的语义分别是？

- **正确判断**：break 结束整个循环，continue 进入下一轮迭代
- **判断依据**：break 让控制流立即离开当前循环；continue 跳过本轮剩余语句并回到循环条件判断处，开始下一轮。二者都可用于 for、while 和 do-while。带标签的 break 与 continue 还能指定外层循环，但滥用标签会让控制流难以追踪，使用前应优先考虑拆分方法。
- **迁移检查**：把题干里的一个条件换成边界值，原来的结论还成立吗？写出判断过程。

### 考点 4：while (true) 循环中最需要注意的风险是？

- **正确判断**：必须存在可到达的退出条件，否则线程会一直占用
- **判断依据**：条件恒真的循环本身合法，常用于事件循环或服务主循环，但必须保证存在 break、return 或抛异常等退出路径，否则线程会一直运行并可能无法正常关闭。Java 允许 while (true)，也不会因此自动创建线程。排查卡死问题时，先确认循环的退出条件与环境状态。
- **迁移检查**：遮住选项，只根据定义复述一次答案，再回来看哪个选项与复述一致。
