## 原理与运行机制

### 机制总览

**教材衔接：什么时候用**

| 需求 | 结构 |
| --- | --- |
| 多次区间求和，数据不变 | 前缀和 |
| 多次区间加减，最后统一读取 | 差分 |
| 区间加减 + 区间求和 | 树状数组 / 线段树 |
| 二维区域求和 | 二维前缀和 |

**失败路径（来自本课错误表）**
- 前缀和数组不预留第 0 位 → 边界判断复杂、易越界 → 多开一位且 `prefix[0] = 0`。
- 区间和写成 `prefix[r] - prefix[l]` → 结果少算一个元素 → 应为 `prefix[r+1] - prefix[l]`。
- 二维前缀和忘记加回左上角 → 子矩阵和多减了一块 → 容斥：加回 `prefix[r1][c1]`。
- 差分右边界写成 `diff[right] -= v` → 影响范围多一格 → 应为 `diff[right + 1] -= v`。

## 代码/协议/SQL 示例

### 最小可验证示例

```python
def build_prefix(nums):
    prefix = [0] * (len(nums) + 1)      # prefix[0] = 0，方便处理边界
    for i, value in enumerate(nums):
        prefix[i + 1] = prefix[i] + value
    return prefix

nums = [3, 1, 4, 1, 5]
prefix = build_prefix(nums)             # [0, 3, 4, 8, 9, 14]
def range_sum(left, right):             # 闭区间 [left, right]
    return prefix[right + 1] - prefix[left]
print(range_sum(1, 3))                  # 1 + 4 + 1 = 6
```

**教材衔接：前缀和：把区间求和降到 O(1)**

预处理 `O(n)`，每次查询 `O(1)`；如果有 m 次查询，总复杂度从 `O(nm)` 降到 `O(n + m)`。

**教材衔接：二维前缀和**

```python
def build_prefix_2d(matrix):
    rows, cols = len(matrix), len(matrix[0])
    prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
    for r in range(rows):
        for c in range(cols):
            prefix[r + 1][c + 1] = (matrix[r][c]
                + prefix[r][c + 1] + prefix[r + 1][c] - prefix[r][c])
    return prefix

def rect_sum(prefix, r1, c1, r2, c2):   # 左上 (r1,c1) 到右下 (r2,c2)
    return (prefix[r2 + 1][c2 + 1] - prefix[r1][c2 + 1]
            - prefix[r2 + 1][c1] + prefix[r1][c1])
```

记忆方式：**大矩形减去上方与左方，再加回被减两次的左上角**。

**教材衔接：前缀和 + 哈希表：和为 k 的子数组**

```python
from collections import defaultdict

def subarray_sum(nums, k):
    count, total = 0, 0
    seen = defaultdict(int)
    seen[0] = 1                      # 前缀和为 0 出现过一次
    for value in nums:
        total += value
        count += seen[total - k]     # 若 total - k 出现过，则存在和为 k 的子数组
        seen[total] += 1
    return count
```

这是把「区间和」转化为「两个前缀和之差」的典型思路。

**教材衔接：差分：区间修改降到 O(1)**

需要给区间 `[l, r]` 同时加上 v，做多次修改后再求最终数组，用差分数组：

```python
def apply_updates(n, updates):
    diff = [0] * (n + 1)
    for left, right, value in updates:
        diff[left] += value
        diff[right + 1] -= value      # 出区间时抵消
    result, running = [], 0
    for i in range(n):
        running += diff[i]            # 前缀和还原
        result.append(running)
    return result
```

```text
原数组:  0 0 0 0 0
操作: [1,3] += 2   ->  diff: [0,+2,0,0,-2]
还原前缀和: 0 2 2 2 0
```

**教材衔接：前缀和与差分模板**

```python
from collections import defaultdict

def build_prefix(nums):
    """一维前缀和：prefix[i] 表示前 i 个元素之和。"""
    prefix = [0] * (len(nums) + 1)
    for i, value in enumerate(nums):
        prefix[i + 1] = prefix[i] + value
    return prefix

def range_sum(prefix, left, right):
    """闭区间 [left, right] 的和，O(1)。"""
    return prefix[right + 1] - prefix[left]

def build_2d_prefix(matrix):
    """二维前缀和：多开一行一列，避免边界判断。"""
    rows, cols = len(matrix), len(matrix[0])
    prefix = [[0] * (cols + 1) for _ in range(rows + 1)]
    for i in range(rows):
        for j in range(cols):
            prefix[i + 1][j + 1] = (
                matrix[i][j]
                + prefix[i][j + 1]
                + prefix[i + 1][j]
                - prefix[i][j]
            )
    return prefix

def sum_region(prefix, r1, c1, r2, c2):
    """子矩阵和（含端点），容斥原理 O(1)。"""
    return (
        prefix[r2 + 1][c2 + 1]
        - prefix[r1][c2 + 1]
        - prefix[r2 + 1][c1]
        + prefix[r1][c1]
    )

def range_add_diff(nums, updates):
    """多次区间加、最后统一求值：差分数组 O(n + q)。"""
    diff = [0] * (len(nums) + 1)
    for left, right, value in updates:
        diff[left] += value
        diff[right + 1] -= value          # 右边界之后要抵消
    result, running = [], 0
    for i, base in enumerate(nums):
        running += diff[i]
        result.append(base + running)
    return result

def subarray_sum_k(nums, k):
    """统计和为 k 的连续子数组个数：前缀和 + 哈希表，O(n)。"""
    seen = defaultdict(int)
    seen[0] = 1                            # 空前缀，处理从头开始的区间
    total = count = 0
    for value in nums:
        total += value
        count += seen[total - k]           # 之前出现过 total - k 的前缀
        seen[total] += 1
    return count
```

### 考点 7：`前缀和`

- **要点**：预先累加数组前缀，使任意区间和可以用两次减法求出。
- **前缀和 的边界**：易错：边界判断复杂、易越界；正确做法是多开一位且 `prefix[0] = 0`。

### 考点 8：`二维前缀和`

- **要点**：用一张表记录左上角到每个位置的累加值，把任意子矩阵求和降到 O(1)。
- **二维前缀和 的边界**：易错：子矩阵和多减了一块；正确做法是容斥：加回 `prefix[r1][c1]`。

### 考点 9：`差分数组`

- **要点**：记录相邻元素的差值，让区间加操作变成两次单点修改，最后求前缀和还原。
- **差分数组 的边界**：易错：最后一段越界；正确做法是开 n+1 长度。

### 考点 10：`第 0 位哨兵`

- **要点**：前缀和数组多留一位并令 prefix[0] = 0，区间和就能统一写成 prefix[r+1] - prefix[l]。
- **第 0 位哨兵 的边界**：只在「前缀和数组多留一位并令 prefix[0] = 0，区间和就能统一写成 prefix[r+1] - prefix[l]」这一前提下成立，换输入或换环境要重新验证。

### 考点 11：排错——前缀和数组不预留第 0 位

- **现象**：边界判断复杂、易越界。
- **处理**：多开一位且 `prefix[0] = 0`。

### 考点 12：排错——区间和写成 `prefix[r] - prefix[l]`

- **现象**：结果少算一个元素。
- **处理**：应为 `prefix[r+1] - prefix[l]`。

### 考点 13：综合辨析——`前缀和` 与 `第 0 位哨兵`

- **辨析点**：`前缀和` 的定义是 预先累加数组前缀，使任意区间和可以用两次减法求出；`第 0 位哨兵` 的定义是 前缀和数组多留一位并令 prefix[0] = 0，区间和就能统一写成 prefix[r+1] - prefix[l]。
- **答题要求**：面对 `前缀和与差分` 的题目，先判断描述的是 `前缀和` 还是 `第 0 位哨兵`，再归到对应定义，最后写出一个会让该定义失效的边界输入。

### 考点 14：排错评分点

- **现象分**：能写出 边界判断复杂、易越界，而不是只写“程序有错”。
- **证据分**：保留触发 前缀和数组不预留第 0 位 的输入、版本和错误原文。
- **修复分**：按 多开一位且 `prefix[0] = 0` 只改一处，并同时回归正常路径与边界路径。
