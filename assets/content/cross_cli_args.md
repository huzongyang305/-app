| Rust | 无 | clap | derive 风格体验最好 |
| Shell | `getopts` | 手动 `while case` | POSIX 内建，够用 |

**教材衔接：退出码约定**

| 码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 运行期错误（文件不存在、处理失败） |
| 2 | 用法错误（参数写错、缺少必填） |
| 126 | 无法执行 |
| 127 | 命令不存在 |
| 130 | 被 Ctrl+C 中断 |

**参数错误返回 2、运行错误返回 1**，这是 Unix 的通用惯例。

```bash
#!/usr/bin/env bash
set -euo pipefail

verbose=0
output=""
mode="safe"

while getopts ":o:vm:h" opt; do
  case "$opt" in
    o) output="$OPTARG" ;;
    v) verbose=1 ;;
    m) mode="$OPTARG" ;;
    h) echo "用法：$0 [-v] [-o 输出] [-m fast|safe] 输入文件"; exit 0 ;;
    \?) echo "未知选项：-$OPTARG" >&2; exit 2 ;;
    :)  echo "选项 -$OPTARG 需要参数" >&2; exit 2 ;;
  esac
done
shift $((OPTIND - 1))
input="${1:?缺少输入文件}"
```
