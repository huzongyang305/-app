## 典型应用场景

- **请求路径里用同步阻塞调用**：典型现象是事件循环被卡住，所有请求变慢；正确做法是改用异步 API 或把重活交给工作线程。
- **未捕获的 Promise 拒绝**：典型现象是进程异常退出；正确做法是统一捕获并记录，设置进程级兜底。
- **依赖不锁定版本**：典型现象是部署结果不一致；正确做法是锁定依赖版本并定期审计漏洞。
