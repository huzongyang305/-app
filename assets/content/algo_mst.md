def linear_search(items, target):
    for index, item in enumerate(items):
        if item == target:
            return index
    return -1

### 从最小示例到完整 Kruskal

下面是带路径压缩的 Kruskal 完整实现，数据与上面的水管图一致：

```python
edges = [(1,"A","B"), (2,"A","C"), (3,"B","C"), (4,"B","D"), (5,"C","D")]
parent = {v: v for v in "ABCD"}

def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]  # 路径压缩
        x = parent[x]
    return x

tree, total = [], 0
for w, u, v in sorted(edges):
    ru, rv = find(u), find(v)
    if ru != rv:  # 已连通就驳回
        parent[ru] = rv
        tree.append(f"{u}-{v}")
        total += w
print(tree, total)
```

保存为 `mst_kruskal.py`，运行 `python mst_kruskal.py`，预期输出：

```text
['A-B', 'A-C', 'B-D'] 7
```

B-C、C-D 被并查集拦下：两端已连通。把 A-B 改成 9 再跑，入选边换成 A-C、B-C、B-D，总和 9，仍是该图的最小值。
