## 核心概念定义

| 术语 | 操作性定义 | 常见边界与风险 |
| --- | --- | --- |
| 二叉树 | 每个节点最多有两个子节点的树结构。 | 易错：稀疏树浪费大量空间；正确做法是用节点指针或哈希表。 |
| 遍历 | 按某种顺序访问数据结构中的每个元素一次。 | 易错：无法区分层级；正确做法是`for _ in range(len(queue))`。 |
| BST | 二叉搜索树：左子树键都小于根、右子树都大于根；平衡时查找 O(log n)，退化成链就是 O(n)。 | 易错：退化成链表，O(n)；正确做法是使用平衡树或先打乱插入。 |
| 红黑树 | 通过颜色约束维持近似平衡的二叉搜索树，查找、插入和删除都保持对数复杂度。 | 易错：拿 AVL 的「左右子树高度差 ≤ 1」来验收红黑树；它只按颜色约束黑高，追求查询更快要换 AVL。 |
| 堆 | 满足堆序的完全二叉树，根节点总是当前集合的最值。 | 易错：把堆当成全局有序的结构来查任意元素，它只保证取最值 O(1)；一旦节点不满足完全二叉树，就没法再用数组下标紧凑存放。 |

## 原理与运行机制

### 机制总览

**教材衔接：平衡树家族**

| 结构 | 特点 |
| --- | --- |
| AVL 树 | 严格平衡，查找快，旋转较频繁 |
| 红黑树 | 近似平衡，插入删除代价低（Java TreeMap、C++ map） |
| B / B+ 树 | 多路平衡，磁盘友好（数据库索引） |
| 堆 | 完全二叉树，取最值 O(1)，常配合优先队列 |

**教材衔接：BST 操作与平衡**

| 操作 | 平均 | 最坏（退化成链） |
| --- | --- | --- |
| 查找 | O(log n) | O(n) |
| 插入 | O(log n) | O(n) |
| 删除 | O(log n) | O(n) |
| 中序遍历 | O(n) | O(n) |

| 平衡结构 | 平衡条件 | 特点 |
| --- | --- | --- |
| AVL 树 | 左右子树高度差 ≤ 1 | 查询更快，旋转更频繁 |
| 红黑树 | 颜色性质约束黑高 | 插入删除旋转少，工程常用 |
| B+ 树 | 多路平衡 | 磁盘索引，扇出大、树矮 |

## 典型应用场景

- **有序数据依次插入 BST**：典型现象是退化成链表，O(n)；正确做法是使用平衡树或先打乱插入。
- **层序遍历不固定层长度**：典型现象是无法区分层级；正确做法是`for _ in range(len(queue))`。
- **删除双子节点直接删除**：典型现象是树结构被破坏；正确做法是用中序后继或前驱替换后再删。
- **递归遍历没有终止条件**：典型现象是无限递归；正确做法是以 `if not node: return` 开头。

### 选择与边界

- 使用 `二叉树` 时，先满足它的定义：每个节点最多有两个子节点的树结构；易错：稀疏树浪费大量空间；正确做法是用节点指针或哈希表。
- 使用 `遍历` 时，先满足它的定义：按某种顺序访问数据结构中的每个元素一次；易错：无法区分层级；正确做法是`for _ in range(len(queue))`。
- 使用 `BST` 时，先满足它的定义：二叉搜索树：左子树键都小于根、右子树都大于根；平衡时查找 O(log n)，退化成链就是 O(n)；易错：退化成链表，O(n)；正确做法是使用平衡树或先打乱插入。
- 使用 `红黑树` 时，先满足它的定义：通过颜色约束维持近似平衡的二叉搜索树，查找、插入和删除都保持对数复杂度；结论随输入规模变化，小规模成立不代表大规模成立，需要重新测量。
- 使用 `堆` 时，先满足它的定义：满足堆序的完全二叉树，根节点总是当前集合的最值；越界、悬垂引用与释放顺序会破坏结论，必须在边界输入下复验。

**教材衔接：二叉树基础**

每个节点最多两个子节点（left / right）。常见术语：根节点、叶子节点、深度、高度、子树。

**教材衔接：四种遍历**

```python
def preorder(node):        # 根 -> 左 -> 右
    if not node:
        return []
    return [node.value] + preorder(node.left) + preorder(node.right)

def inorder(node):         # 左 -> 根 -> 右：二叉搜索树得到升序
    if not node:
        return []
    return inorder(node.left) + [node.value] + inorder(node.right)

def postorder(node):       # 左 -> 右 -> 根：适合释放资源
    if not node:
        return []
    return postorder(node.left) + postorder(node.right) + [node.value]

from collections import deque

def level_order(root):     # 层序遍历（BFS）
    if not root:
        return []
    result, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.value)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level)
    return result
```

**教材衔接：二叉搜索树（BST）**

性质：任意节点的左子树全部小于它，右子树全部大于它。

```python
def search(node, target):
    while node:
        if target == node.value:
            return node
        node = node.left if target < node.value else node.right
    return None

def insert(node, value):
    if not node:
        return TreeNode(value)
    if value < node.value:
        node.left = insert(node.left, value)
    elif value > node.value:
        node.right = insert(node.right, value)
    return node
```

平均查找 `O(log n)`，但插入有序数据会退化成链表，最坏 `O(n)`。

**教材衔接：遍历速查**

| 遍历 | 顺序 | 典型用途 | 实现方式 |
| --- | --- | --- | --- |
| 前序 | 根 → 左 → 右 | 复制树、序列化 | 递归 / 栈 |
| 中序 | 左 → 根 → 右 | BST 得到升序序列 | 递归 / 栈 |
| 后序 | 左 → 右 → 根 | 释放树、计算子树聚合 | 递归 / 栈 |
| 层序 | 逐层从左到右 | 求深度、按层处理 | 队列 |

```python
from collections import deque

class TreeNode:
    __slots__ = ("value", "left", "right")

    def __init__(self, value, left=None, right=None):
        self.value, self.left, self.right = value, left, right

def inorder(root):
    """迭代版中序遍历：BST 上得到升序序列。"""
    result, stack = [], []
    cur = root
    while cur or stack:
        while cur:              # 一路向左压栈
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        result.append(cur.value)
        cur = cur.right
    return result

def level_order(root):
    """层序遍历，按层返回列表。"""
    if not root:
        return []
    levels, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):     # 固定当前层长度
            node = queue.popleft()
            level.append(node.value)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        levels.append(level)
    return levels

def insert(root, value):
    """BST 插入：小于走左、大于走右，重复值不插入。"""
    if root is None:
        return TreeNode(value)
    if value < root.value:
        root.left = insert(root.left, value)
    elif value > root.value:
        root.right = insert(root.right, value)
    return root
```

## 术语速查

| 术语 | 一句话说明 |
| --- | --- |
| `二叉树` | 每个节点最多有两个子节点的树结构。 |
| `遍历` | 按某种顺序访问数据结构中的每个元素一次。 |
| `BST` | 二叉搜索树：左子树键都小于根、右子树都大于根；平衡时查找 O(log n)，退化成链就是 O(n)。 |
| `红黑树` | 通过颜色约束维持近似平衡的二叉搜索树，查找、插入和删除都保持对数复杂度。 |
| `堆` | 满足堆序的完全二叉树，根节点总是当前集合的最值。 |

**术语关系**：`二叉树`（每个节点最多有两个子节点的树结构） → `遍历`（按某种顺序访问数据结构中的每个元素一次） → `BST`（二叉搜索树：左子树键都小于根、右子树都大于根） → `红黑树`（通过颜色约束维持近似平衡的二叉搜索树）。

### 考点 7：`二叉树`

- **要点**：每个节点最多有两个子节点的树结构。
- **二叉树 的边界**：易错：稀疏树浪费大量空间；正确做法是用节点指针或哈希表。

### 考点 8：`遍历`

- **要点**：按某种顺序访问数据结构中的每个元素一次。
- **遍历 的边界**：易错：无法区分层级；正确做法是`for _ in range(len(queue))`。

### 考点 9：`BST`

- **要点**：二叉搜索树：左子树键都小于根、右子树都大于根；平衡时查找 O(log n)，退化成链就是 O(n)。
- **BST 的边界**：易错：退化成链表，O(n)；正确做法是使用平衡树或先打乱插入。

### 考点 10：`红黑树`

- **要点**：通过颜色约束维持近似平衡的二叉搜索树，查找、插入和删除都保持对数复杂度。
- **红黑树 的边界**：结论随输入规模变化，小规模成立不代表大规模成立，需要重新测量。

### 考点 11：`堆`

- **要点**：满足堆序的完全二叉树，根节点总是当前集合的最值。
- **堆 的边界**：越界、悬垂引用与释放顺序会破坏结论，必须在边界输入下复验。

### 考点 12：排错——有序数据依次插入 BST

- **现象**：退化成链表，O(n)。
- **处理**：使用平衡树或先打乱插入。

### 考点 13：排错——层序遍历不固定层长度

- **现象**：无法区分层级。
- **处理**：`for _ in range(len(queue))`。

### 考点 14：综合辨析——`二叉树` 与 `堆`

- **辨析点**：`二叉树` 的定义是 每个节点最多有两个子节点的树结构；`堆` 的定义是 满足堆序的完全二叉树，根节点总是当前集合的最值。
- **答题要求**：面对 `树与二叉搜索树` 的题目，先判断描述的是 `二叉树` 还是 `堆`，再归到对应定义，最后写出一个会让该定义失效的边界输入。

### 考点 15：排错评分点

- **现象分**：能写出 退化成链表，O(n)，而不是只写“程序有错”。
- **证据分**：保留触发 有序数据依次插入 BST 的输入、版本和错误原文。
- **修复分**：按 使用平衡树或先打乱插入 只改一处，并同时回归正常路径与边界路径。
