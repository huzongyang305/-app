## 关键代码

```bash
#!/usr/bin/env bash
set -euo pipefail
LOG=${1:-/var/log/nginx/access.log}
Total=$(wc -l < "$LOG")
Errors=$(awk '$9 >= 500 {count++} END {print count+0}' "$LOG")
Rate=$(awk -v e="$Errors" -v t="$Total" 'BEGIN { if (t>0) printf "%.4f", e/t; else print 0 }')
printf 'total=%s errors=%s error_rate=%s\n' "$Total" "$Errors" "$Rate"
```

## 考点精讲

### 考点 1：概念判断·awk

- **题目**：日志文件为空时，这段脚本中的错误率计算应该返回什么？
- **判断依据**：脚本在 awk BEGIN 中显式判断分母 t 是否大于 0，为空时输出 0，避免除零并保证日报格式稳定。错误率没有样本时不能用 NaN 或无限大表示，脚本也不应因此中断。「实战：Shell 日志分析与告警」要求先交代awk、jq、日志分析的前提再下结论，所以“0”只在题干“日志文件为空时”给定的条件下成立。
