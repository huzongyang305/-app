下面示例用于验证 类 的最小输入、处理和输出。先原样运行，再只修改一个值：

```kotlin
class Counter(private var value: Int = 0) {
    fun increment() {
        value++
    }

    override fun toString() = "counter=$value"
}

fun main() {
    val counter = Counter()
    repeat(3) { counter.increment() }
    println(counter)
}
```
