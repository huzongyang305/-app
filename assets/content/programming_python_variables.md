
### 考点 7：`变量`

- **要点**：变量是给数据起的一个名字。Python 是动态类型语言：变量本身没有类型，值才有类型，同一个变量可以先后指向不同类型的值。
- **变量 的边界**：易错：语法错误或行为异常；正确做法是避开 `list`、`dict`、`type`、`sum` 等内置名。

### 考点 8：`类型`

- **要点**：值允许的表示、取值范围和可执行操作集合。
- **类型 的边界**：易错：`TypeError: can only concatenate str`；正确做法是类型不匹配，先转换：`int("10") + 1`。

### 考点 9：`类型注解`

- **要点**：在参数与返回值上标注期望类型，解释器不强制，但检查器与编辑器会据此提示。
- **类型注解 的边界**：静态检查只在编译期成立，运行期输入仍需校验。

### 考点 10：`作用域`

- **要点**：LEGB 规则决定名字从局部、闭包、全局到内置的查找顺序，global 与 nonlocal 用来写外层变量。
- **作用域 的边界**：只在「LEGB 规则决定名字从局部、闭包、全局到内置的查找顺序，global 与 nonlocal 用来写外层变量」这一前提下成立，换输入或换环境要重新验证。

### 考点 11：排错——用 `is` 比较值

- **现象**：小整数有时对、有时错。
- **处理**：值比较用 `==`，`is` 只判断是不是同一个对象。

### 考点 12：排错——浮点数直接比相等

- **现象**：`0.1 + 0.2 == 0.3` 是 `False`。
- **处理**：用 `abs(a - b) < 1e-9` 判断。

### 考点 13：综合辨析——`变量` 与 `作用域`

- **辨析点**：`变量` 的定义是 变量是给数据起的一个名字。Python 是动态类型语言：变量本身没有类型，值才有类型，同一个变量可以先后指向不同类型的值；`作用域` 的定义是 LEGB 规则决定名字从局部、闭包、全局到内置的查找顺序，global 与 nonlocal 用来写外层变量。
