## 核心概念定义

| 术语 | 一句话说明 |
| --- | --- |
| for 循环 | 把初始化、条件、更新写在一行，适合次数确定的循环。 |
| while 循环 | 条件为真就执行，适合次数由运行情况决定的循环。 |
| do-while | 先执行一次再判断条件，循环体至少执行一次。 |
| break 与 continue | `break` 结束整个循环，`continue` 跳过本轮剩余语句。 |
| 循环变量作用域 | 在 `for` 的括号里声明的变量只在循环内可见。 |
| 无限循环 | 条件永远为真的循环，必须用 `break` 或外部条件退出。 |

## 原理与运行机制

### for 循环：计数器式重复

```cpp
for (int i = 0; i < 5; ++i) {
    std::cout << i << " ";
}
// 输出：0 1 2 3 4
```

`for` 循环把三件事写在一行：
1. **初始化** `int i = 0`：循环开始前做一次
2. **条件** `i < 5`：每轮开始前检查，为假就停
3. **更新** `++i`：每轮结束后做一次

把它想象成跑步训练：先站到起跑线（初始化），每跑一圈看是否到了 5 圈（条件），跑完一圈就计数器加 1（更新）。

### while 循环：条件式重复

```cpp
int n = 100;
while (n > 1) {
    if (n % 2 == 0) n = n / 2;
    else n = 3 * n + 1;
    std::cout << n << " ";
}
```

`while` 只关心条件：条件为真就执行循环体，条件为假就退出。适合"不知道要循环多少次，但知道什么时候该停"的场景。

### do-while：至少执行一次

```cpp
int choice;
do {
    std::cout << "请输入 1-3：";
    std::cin >> choice;
} while (choice < 1 || choice > 3);
```

`do-while` 先执行循环体，再检查条件。这意味着循环体**至少执行一次**。适合"先做一次，不满意就重来"的场景，比如菜单选择。

### break 与 continue

```cpp
for (int i = 0; i < 10; ++i) {
    if (i == 5) break;       // i 到 5 就彻底退出循环
    if (i % 2 == 0) continue; // 偶数就跳过本轮剩余代码
    std::cout << i << " ";
}
// 输出：1 3
```

- `break`：立刻结束整个循环，跳到循环后面的代码
- `continue`：跳过本轮循环体剩余的代码，直接进入下一轮

### ++i 与 i++

```cpp
for (int i = 0; i < 3; ++i) {
    std::cout << i;
}
// 输出：012
```

在 `for` 循环的更新表达式里，`++i` 和 `i++` 效果完全相同——都让 `i` 加 1。它们的区别只在作为表达式使用时才体现（`++i` 先加后用，`i++` 先用后加），但作为独立的更新语句没有差别。

## 典型应用场景

循环是编程中最常用的结构之一：

- **遍历数据**：逐个处理数组或列表中的每个元素
- **累加计算**：求 1+2+...+100 的和
- **重复提示**：直到用户输入合法值为止
- **搜索**：在一堆数据中查找目标
- **模拟**：重复执行某个过程直到收敛

### 一个实际的小例子

```cpp
#include <iostream>

int main() {
    int sum = 0;
    for (int i = 1; i <= 100; ++i) {
        sum += i;
    }
    std::cout << "1 到 100 的和是：" << sum << "\n";
    return 0;
}
```

输出：`1 到 100 的和是：5050`

## 代码/协议/SQL 示例

### 最小可运行示例

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 3; ++i) {
        std::cout << i;
    }
    return 0;
}
```

输出：

```text
012
```

### 完整示例：九九乘法表

```cpp
#include <iostream>

int main() {
    for (int i = 1; i <= 9; ++i) {
        for (int j = 1; j <= i; ++j) {
            std::cout << j << "x" << i << "=" << i * j << "\t";
        }
        std::cout << "\n";
    }
    return 0;
}
```

## 时间/空间复杂度或性能分析

循环是时间复杂度的主要来源：

- 一层 `for` 循环从 0 到 n：O(n)
- 两层嵌套循环：O(n^2)
- 循环体内有常数操作：不改变量级

注意：循环次数很多时（百万级以上），循环体内的操作效率就变得重要。避免在循环内做不必要的内存分配或函数调用。

## 常见误区与易错点

| 容易犯的错误 | 会出现什么 | 怎么修 |
| --- | --- | --- |
| 边界差一（off-by-one） | 少循环一次或多循环一次 | 仔细检查 `<=` 还是 `<` |
| 用无符号数反向遍历 | 减到 0 后回绕成很大的数，循环不结束 | 用带符号下标，或先判断再自减 |
| 循环里修改容器大小 | 迭代器失效，程序崩溃 | 不要在范围 for 里增删元素 |
| `continue` 与 `break` 混用 | 逻辑混乱，循环提前结束 | `break` 跳出整体，`continue` 只跳本轮 |
| 忘记更新循环变量 | 无限循环 | 确认 `for` 的第三个表达式或 `while` 体内有更新 |

### 现场 1：用无符号数反向遍历

**症状**：循环不结束，或者访问了越界的下标。

**根因与修复**：无符号数减到 0 后再减 1 会回绕成最大值。用带符号下标，或先判断再自减。
