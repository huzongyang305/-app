## 核心概念定义

| 术语 | 操作性定义 | 常见边界与风险 |
| --- | --- | --- |
| async | 标记异步函数或异步块，使内部可以使用 await 而不阻塞调用线程。 | 标了 async 不等于工作自动离开主线程：耗时调用仍压在调用线程上，界面照样卡顿甚至无响应。 |
| Actor | 把状态封装在独立执行单元中，通过消息异步通信的并发模型。 | 隔离只在可变状态真被放进执行单元时才成立；共享状态漏了隔离标注，就会出现编译告警或运行期异常。 |
| Task | Swift 并发中的异步任务单元，可等待结果、取消或组合并发工作。 | 取消是协作式的：不在关键点检查并向下传播，页面都退出了任务还在跑，资源也没释放。 |
| Sendable | Swift 中标记类型可安全跨并发域传递的协议。 | 它管的是跨隔离边界传数据这一环：不满足就编译告警；标上它也不等于状态已被 Actor 隔离。 |

### 选择与边界

- 使用 `async` 时，标记异步函数或异步块，使内部可以使用 await 而不阻塞调用线程；共享状态与调度顺序会改变结论，单线程或串行测试通过不等于并发下成立。
- 使用 `Actor` 时，把状态封装在独立执行单元中，通过消息异步通信的并发模型；共享状态与调度顺序会改变结论，单线程或串行测试通过不等于并发下成立。
- 使用 `Task` 时，Swift 并发中的异步任务单元，可等待结果、取消或组合并发工作；共享状态与调度顺序会改变结论，单线程或串行测试通过不等于并发下成立。
- 使用 `Sendable` 时，Swift 中标记类型可安全跨并发域传递的协议；共享状态与调度顺序会改变结论，单线程或串行测试通过不等于并发下成立。
