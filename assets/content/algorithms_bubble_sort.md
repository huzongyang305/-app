## 原理与运行机制

### 机制总览

**教材衔接：核心思想**

冒泡排序重复遍历数组，比较相邻两个元素，如果顺序不对就交换。每一轮结束后，最大的元素会像气泡一样「浮」到末尾。

**教材衔接：稳定性**

当 `nums[j] > nums[j+1]` 时才交换（注意不是 `>=`），相等元素不会互换位置，因此冒泡排序是**稳定排序**。

**教材衔接：什么时候用它**

冒泡排序效率低，实际工程中很少使用。它的价值在于：

- 理解「交换」和「多轮比较」的基本模式。
- 作为教学示例，帮助建立复杂度和稳定性的直觉。

实际排序请使用语言内置实现，例如 Python 的 `sorted()`，它采用 Timsort，平均 `O(n log n)`。

**教材衔接：冒泡排序实现要点**

```python
def bubble_sort(nums):
    """带提前退出与有序区收缩的冒泡排序。"""
    arr = nums[:]                      # 不改原数组
    n = len(arr)
    for end in range(n - 1, 0, -1):    # 每轮确定一个最大值
        swapped = False
        for i in range(end):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
                swapped = True
        if not swapped:                # 本轮无交换：已经有序
            break
    return arr

assert bubble_sort([5, 1, 4, 2, 8]) == [1, 2, 4, 5, 8]
assert bubble_sort([]) == []
assert bubble_sort([1]) == [1]
```

| 优化 | 收益 |
| --- | --- |
| `swapped` 标记 | 已有序时最好情况降到 O(n) |
| 收缩右边界 | 每轮少比较一次 |
| 记录最后交换位置 | 后面已有序，可一次跳过更多 |
| 鸡尾酒（双向）冒泡 | 缓解「小元素在末尾」的慢速移动 |

```python
def bubble_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        swapped = False
        # 每一轮比较到 n-1-i，后面已经有序
        for j in range(n - 1 - i):
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]
                swapped = True
        if not swapped:      # 本轮没有交换，说明已经有序
            break
    return nums

print(bubble_sort([5, 3, 8, 1]))  # [1, 3, 5, 8]
```

### 考点 7：`冒泡排序`

- **要点**：冒泡排序 = 相邻比较 + 交换 + 提前退出优化。
- **冒泡排序 的边界**：只在「冒泡排序 = 相邻比较 + 交换 + 提前退出优化」这一前提下成立，换输入或换环境要重新验证。

### 考点 8：`稳定性`

- **要点**：相等元素在排序前后相对顺序不变；冒泡只在严格逆序时交换，所以是稳定的。
- **稳定性 的边界**：只在「相等元素在排序前后相对顺序不变；冒泡只在严格逆序时交换，所以是稳定的」这一前提下成立，换输入或换环境要重新验证。

### 考点 9：`交换排序`

- **要点**：通过反复比较相邻元素并交换来消除逆序对的排序思路，冒泡与鸡尾酒排序都属于这一类。
- **交换排序 的边界**：只在「通过反复比较相邻元素并交换来消除逆序对的排序思路，冒泡与鸡尾酒排序都属于这一类」这一前提下成立，换输入或换环境要重新验证。

### 考点 10：`提前退出`

- **要点**：某一轮没有发生任何交换就说明序列已经有序，可以直接结束循环。
- **提前退出 的边界**：易错：最好情况仍是 O(n²)；正确做法是加提前退出。

### 考点 11：排错——内层循环写成 `range(n)`

- **现象**：多比较无效元素。
- **处理**：应为 `range(end)`。

### 考点 12：排错——比较写成 `>=`

- **现象**：相等元素被交换，不再稳定。
- **处理**：用 `>` 保持稳定。

### 考点 13：综合辨析——`冒泡排序` 与 `提前退出`

- **辨析点**：`冒泡排序` 的定义是 冒泡排序 = 相邻比较 + 交换 + 提前退出优化；`提前退出` 的定义是 某一轮没有发生任何交换就说明序列已经有序，可以直接结束循环。
- **答题要求**：面对 `冒泡排序` 的题目，先判断描述的是 `冒泡排序` 还是 `提前退出`，再归到对应定义，最后写出一个会让该定义失效的边界输入。

### 考点 14：排错评分点

- **现象分**：能写出 多比较无效元素，而不是只写“程序有错”。
- **证据分**：保留触发 内层循环写成 `range(n)` 的输入、版本和错误原文。
