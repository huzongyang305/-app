## 典型应用场景

- **用 `==`**：典型现象是结果反直觉；正确做法是用 `===`。
- **把 `NaN` 当相等**：典型现象是`NaN === NaN` 是 false；正确做法是用 `Number.isNaN(x)`。
- **直接调 `parseInt` 忘传进制**：典型现象是老浏览器把 `08` 当八进制；正确做法是写 `parseInt(s, 10)`。
- **数字精度**：典型现象是`0.1 + 0.2 !== 0.3`；正确做法是用误差比较，金额用整数分。
