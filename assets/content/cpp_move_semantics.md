## 最小可运行示例

下面示例用于验证「C++ 移动语义与右值引用」的最小输入、处理和输出。先原样运行，再只修改一个值：

```cpp
#include <iostream>
#include <string>
#include <utility>

int main() {
    std::string source = "payload";
    std::string target = std::move(source);
    std::cout << "target=" << target << "\n";
    return 0;
}
```
