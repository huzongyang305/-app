## 本节知识框架

在学 Python 之前，先看看这节课会覆盖哪些内容，以及它们之间的关系：

```text
Python 基础语法
├── 缩进规则 ──── Python 用缩进来划分代码块（不像其他语言用大括号）
├── 注释 ──────── 写给人看的说明，电脑会跳过
├── 运算符 ────── 加、减、乘、除、比较……对数据做运算的符号
├── 表达式 ────── 能算出一个值的一段代码
├── 语句 ──────── 电脑执行的一个完整动作

```

你可以把 Python 想象成一本「写给电脑的菜谱」：你写一行，电脑就照着做一步。而这节课要学的，就是这本菜谱最基本的书写格式。

## 核心概念定义

先把最重要的几个术语搞清楚，后面学什么都围绕它们展开。

**缩进（Indentation）**
Python 用行首的空格数量来表示代码的层级关系。就像写信时每个段落开头要空两格一样，Python 里同一个代码块的每一行必须缩进相同数量的空格。官方推荐用 **4 个空格**，千万不要混用 Tab 和空格。

**注释（Comment）**
用 `#` 开头的文字，Python 会完全忽略它。注释就像贴在代码旁边的便条——写给你自己或者别的程序员看的，电脑根本不理它。

**运算符（Operator）**
对数据进行操作的符号。比如 `+` 是加法，`-` 是减法，`==` 是判断是否相等。你可以把运算符想象成厨房里的工具：刀用来切菜，锅用来炒菜，不同的工具做不同的事。

**表达式（Expression）**
一段能「算出结果」的代码。比如 `1 + 2` 是一个表达式，它的结果是 `3`；`"hello" + " world"` 也是表达式，结果是 `"hello world"`。表达式的核心特征：**它一定会产出一个值**。

**语句（Statement）**
电脑执行的某个完整动作。比如 `x = 10` 是一条赋值语句，`print("你好")` 是一条输出语句。语句不一定产出值，但它一定会「做某件事」。

**语句 vs 表达式的区别**：表达式产出值，语句执行动作。`x + 1` 是表达式（产出 x 加 1 的结果），`x = x + 1` 是语句（把结果赋值给 x）。你可以这样记：表达式可以放在等号右边，语句不行。

## 原理与运行机制

### Python 是怎么运行你的代码的？

Python 是一门**解释型语言**。这意味着你写的代码不需要事先编译成机器码，而是由 Python 解释器逐行读取、逐行执行。就像翻译官一边听你说话一边翻译，而不是等你说完一整篇再翻译。

运行流程很简单：

```text
你写的代码 (.py 文件)
    ↓
Python 解释器逐行读取
    ↓
遇到 print() → 输出到屏幕
遇到 input() → 等待用户输入
遇到运算     → 算出结果
遇到错误     → 停下来并报告
```

### 缩进为什么这么重要？

在 C、Java 这些语言里，代码块用大括号 `{}` 括起来，缩进只是为了好看。但 Python 不一样——**缩进本身就是语法**。少一个空格或多一个空格，程序的含义可能就完全不同，甚至直接报错。

想象你在读一本书：

```text
第一章
  第一节
    内容 A
    内容 B
  第二节
    内容 C
```

你一看缩进就知道「内容 A 和内容 B 属于第一节」。Python 也是这样理解代码的。

### 运算符的优先级

和数学里一样，Python 的运算符也有优先级：

| 优先级（从高到低） | 运算符 | 含义 |
| --- | --- | --- |
| 1 | `**` | 幂运算 |
| 2 | `*`, `/`, `//`, `%` | 乘、除、整除、取余 |
| 3 | `+`, `-` | 加、减 |
| 4 | `==`, `!=`, `<`, `>` | 比较运算 |
| 5 | `and`, `or`, `not` | 逻辑运算 |

拿不准的时候，加括号最保险：`(1 + 2) * 3` 永远比 `1 + 2 * 3` 清楚。

## 典型应用场景

**场景 1：写第一个程序**
每个程序员的起点都是 `print("Hello, World!")`。这行代码做的事情很简单：把括号里的文字显示到屏幕上。

**场景 2：和用户交互**
用 `input()` 问用户一个问题，用 `print()` 把结果反馈回去。比如一个计算年龄的小工具：

```python
name = input("你叫什么名字？")
print("你好，" + name + "！")
```

**场景 3：做数学计算**
Python 可以当计算器用，而且比手机计算器更灵活：

```python
price = 99
count = 3
total = price * count
print(f"总价：{total} 元")
```

**场景 4：给代码写说明**
代码写完过一个月，你可能自己都看不懂了。注释就是给未来的自己留便条：

```python
# 计算折扣价：原价打八折
discount_price = original_price * 0.8
```

## 代码/协议/SQL 示例

### 示例 1：最简单的 Python 程序

```python
# 第一个 Python 程序
print("Hello, World!")
```

就这一行代码（不算注释），完成了你的第一个程序。`print()` 是一个内置函数，负责把内容输出到屏幕。

### 示例 2：和用户打招呼

```python
# 读取用户输入并打招呼
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

这里出现了两个新概念：
- `input()` 会暂停程序，等用户输入内容并按回车，然后把输入的内容作为字符串返回。
- `f"你好，{name}！"` 是 f-string 格式化字符串，`{name}` 会被替换成变量 `name` 的值。

### 示例 3：缩进的作用

```python
score = 85

if score >= 60:
    print("及格")       # 缩进 4 个空格 → 属于 if 分支
else:
    print("不及格")     # 缩进 4 个空格 → 属于 else 分支

print("程序结束")       # 没有缩进 → 无论条件如何都会执行
```

注意看缩进：`print("及格")` 前面有 4 个空格，说明它属于 `if` 分支。`print("程序结束")` 没有缩进，说明它不在任何分支里，一定会执行。

### 示例 4：运算符和表达式

```python
# 算术运算
a = 10
b = 3
print(a + b)     # 加法：13
print(a - b)     # 减法：7
print(a * b)     # 乘法：30
print(a / b)     # 除法：3.333...（结果是浮点数）
print(a // b)    # 整除：3（只取整数部分）
print(a % b)     # 取余：1（10 除以 3 余 1）
print(a ** b)    # 幂运算：1000（10 的 3 次方）

# 比较运算（结果是 True 或 False）
print(a > b)     # True
print(a == b)    # False
print(a != b)    # True

# 逻辑运算
x = True
y = False
print(x and y)   # False（两个都为 True 才是 True）
print(x or y)    # True（至少一个为 True 就是 True）
print(not x)     # False（取反）
```

### 示例 5：input() 的陷阱——类型转换

```python
# 错误示范：input() 返回的永远是字符串
age_text = input("请输入年龄：")
# 如果用户输入 18，age_text 的值是 "18"（字符串），不是 18（数字）

# 直接做算术会报错：
# age_text + 1  →  TypeError!

# 正确做法：先转换成数字
age = int(age_text)    # 把字符串 "18" 转成数字 18
print(f"明年你 {age + 1} 岁")
```

这是一个新手必踩的坑：`input()` 拿回来的东西**永远是字符串**，想做数学运算必须先用 `int()` 或 `float()` 转换。

### 示例 6：语句 vs 表达式

```python
# 表达式：能算出一个值
1 + 2              # 表达式，值为 3
len("hello")       # 表达式，值为 5
x > 10             # 表达式，值为 True 或 False

# 语句：执行一个动作
x = 10             # 赋值语句
print("你好")      # 输出语句
if x > 5:          # 条件语句
    pass
```

### 示例 7：综合练习——问候小程序

```python
# 问用户姓名和出生年份，输出问候语
name = input("请输入你的名字：").strip()
year_text = input("请输入出生年份（如 2000）：").strip()

if not year_text.isdigit():
    print("年份只能是数字哦！")
else:
    age = 2026 - int(year_text)
    print(f"你好，{name}，你大约 {age} 岁")
```

逐行解释：
- `.strip()` 去掉用户不小心输入的首尾空格。
- `.isdigit()` 检查字符串是否全是数字，防止程序崩溃。
- `int(year_text)` 把字符串转成整数，才能做减法。
- f-string 把变量直接嵌入字符串，比用 `+` 拼接清晰得多。

## 时间/空间复杂度或性能分析

Python 基础语法的各项操作在性能上几乎不需要担心：

| 操作 | 时间复杂度 | 说明 |
| --- | --- | --- |
| `print()` 输出 | O(n) | n 是输出内容的长度 |
| `input()` 读取 | O(n) | n 是用户输入的长度 |
| 算术运算 | O(1) | 普通整数运算可以看作常数时间 |
| 字符串拼接 | O(n+m) | n 和 m 是两个字符串的长度 |
| 类型转换 `int()` | O(n) | n 是字符串长度 |

对于初学者来说，记住一点就行：**基础操作都很快，不用担心性能问题**。等你写到需要处理百万级数据的时候，再考虑优化也不迟。

## 常见误区与易错点

### 误区 1：混用 Tab 和空格

**现象**：程序报 `IndentationError` 或 `TabError`。

**原因**：同一个文件里，有些地方用 Tab 缩进，有些地方用空格缩进。Python 看到这种不一致就会罢工。

**正确做法**：全程用 4 个空格。大多数编辑器可以设置「按 Tab 键自动插入 4 个空格」，打开这个选项就一劳永逸了。

### 误区 2：忘了 `input()` 返回的是字符串

**现象**：`"18" + 1` 报 `TypeError`。

**原因**：`input()` 不管用户输入什么，返回的都是字符串类型。字符串和数字不能直接做算术运算。

**正确做法**：先用 `int()` 或 `float()` 转换，再做运算。

### 误区 3：用中文标点符号

**现象**：程序报 `SyntaxError: invalid character`。

**原因**：代码里的括号、引号、冒号、逗号都必须是英文半角符号。中文全角符号长得很像但 Python 不认识。

**正确做法**：写代码时切换到英文输入法。`print("你好")` 里的引号必须是英文的 `""`，不能是中文的 `""`。

### 误区 4：用 `print "hello"` 而不是 `print("hello")`

**现象**：程序报 `SyntaxError`。

**原因**：Python 2 里 `print` 是一个语句，可以不加括号。但 Python 3 里 `print` 是一个函数，必须加括号。

**正确做法**：永远写 `print("内容")`，带括号。

### 误区 5：用 `=` 做比较

**现象**：程序报 `SyntaxError`。

**原因**：`=` 是赋值运算符（把右边的值放进左边的变量），`==` 才是比较运算符（判断两边是否相等）。

**正确做法**：比较用 `==`，赋值用 `=`。`if x == 10:` 是对的，`if x = 10:` 是错的。

### 误区 6：用 `is` 比较值

**现象**：`a = 1000; b = 1000; print(a is b)` 结果可能是 `False`。

**原因**：`is` 判断的是两个变量是否指向同一个对象（内存地址是否相同），而不是值是否相等。

**正确做法**：比较值用 `==`，`is` 一般只用来和 `None` 比较。

### 误区 7：代码块下没有内容

**现象**：`IndentationError: expected an indented block`。

**原因**：`if`、`for`、`while`、`def`、`class` 这些关键字后面必须跟一个缩进的代码块。如果暂时没想好写什么，至少放一个 `pass`。

**正确做法**：

```python
if condition:
    pass    # 占位，表示「这里以后会填代码」
```

- **正确项**：IndentationError
- **判断依据**：本题正确项是IndentationError。术语 缩进（Python 基础语法）：Python 用缩进表示代码块，同一代码块必须使用相同数量的空格，官方推荐 4 个空格，不要混用 Tab 和空格，本题取IndentationError这条。易错点是用 `print "hello"` 而不是 `print("hello")`，会造成程序报 `SyntaxError`，改法是永远写 `print("内容")`，带括号。

### 考点 5

- **题目**：下列哪些是 Python 的内置不可变类型？请选择所有正确答案。
- **正确项**：int；tuple
- **判断依据**：术语 Python（Python 基础语法）：一种解释型通用编程语言，用缩进划分代码块，标准库覆盖面广，本题取int这条。易错点是用 `=` 做比较，会造成程序报 `SyntaxError`，改法是比较用 `==`，赋值用 `=`。

### 考点 6

- **题目**：关于 `TypeError`，下列哪些说法与 `Python 基础语法` 的正文一致？判断时以从第一个程序开始，掌握缩进、注释与输入输出。为主线。（多选）
- **正确项**：int、str、tuple；字符串 str
- **判断依据**：本题正确项是int、str、tuple。术语 TypeError（Python 基础语法）：常见错误：直接对 `input()` 的结果做加法会得到字符串拼接，`"18" + 1` 会抛出 `TypeError`，本题取int、str、tuple这条。易错点是用 `is` 比较值，会造成`a = 1000; b = 1000; print(a is b)` 结果可能是 `False`，改法是比较值用 `==`，`is` 一般只用来和 `None` 比较。
