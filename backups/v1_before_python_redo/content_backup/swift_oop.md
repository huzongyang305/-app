- **要点**：自动引用计数：编译期插入引用计数管理对象生命周期，循环引用需用 weak 或 unowned 打破。
- **ARC 的边界**：静态检查只在编译期成立，运行期输入仍需校验。

### 考点 10：`协议组合`

- **要点**：二、运行时与内存模型：围绕「struct、class、ARC、协议组合」说明变量生命周期、资源释放、并发模型和错误传播。

### 考点 12：排错——强引用形成环

- **现象**：对象无法释放。
- **处理**：用弱引用打破循环。
