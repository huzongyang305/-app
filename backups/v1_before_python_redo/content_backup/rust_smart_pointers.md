### 从概念到验证的学习链条

1. `Box`：先掌握 把值分配到堆上的智能指针，用于递归类型、大对象或需要稳定地址的场景，再用它解释 `Rc 与 Arc` 为什么会出现。
2. `Rc 与 Arc`：先掌握 引用计数智能指针，Rc 用于单线程共享，Arc 用原子计数以便跨线程，再用它解释 `内部可变性` 为什么会出现。
3. `内部可变性`：先掌握 在共享引用下也能修改数据，借用检查从编译期挪到运行期或锁里，再用它解释 `Weak` 为什么会出现。
4. `Weak`：先掌握 不增加引用计数的弱引用，用来打破 Rc 与 Arc 之间的循环引用，再用它解释 `Rust` 为什么会出现。
5. `Rust`：先掌握 Rust 是系统级语言，用编译期检查替代垃圾回收，做到内存安全与零成本抽象，再用它解释 `所有权` 为什么会出现。
6. `所有权`：先掌握 每个值只有一个所有者，离开作用域就释放；跨线程共享要用 Arc 与 Mutex，再用它解释 本课示例的观察结果 为什么会出现。

### 考点 7：`Box`

- **要点**：把值分配到堆上的智能指针，用于递归类型、大对象或需要稳定地址的场景。
- **Box 的边界**：静态检查只在编译期成立，运行期输入仍需校验。

### 考点 8：`Rc 与 Arc`

- **要点**：引用计数智能指针，Rc 用于单线程共享，Arc 用原子计数以便跨线程。
- **Rc 与 Arc 的边界**：共享状态与调度顺序会改变结论，单线程或串行测试通过不等于并发下成立。

### 考点 9：`内部可变性`

- **要点**：在共享引用下也能修改数据，借用检查从编译期挪到运行期或锁里。
- **内部可变性 的边界**：易错：运行期借用冲突；正确做法是优先用编译期借用检查，必要时缩小可变范围。

### 考点 10：`Weak`

- **要点**：不增加引用计数的弱引用，用来打破 Rc 与 Arc 之间的循环引用。
- **Weak 的边界**：越界、悬垂引用与释放顺序会破坏结论，必须在边界输入下复验。

### 考点 11：`Rust`

- **要点**：Rust 是系统级语言，用编译期检查替代垃圾回收，做到内存安全与零成本抽象
- **Rust 的边界**：静态检查只在编译期成立，运行期输入仍需校验。

### 考点 12：`所有权`

- **要点**：每个值只有一个所有者，离开作用域就释放；跨线程共享要用 Arc 与 Mutex
- **所有权 的边界**：易错：编译不过或出现未定义行为；正确做法是使用线程安全的共享类型并明确所有权。
