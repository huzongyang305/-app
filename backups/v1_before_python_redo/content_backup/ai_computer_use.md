## 典型应用场景

- **只靠像素坐标点击**：典型现象是分辨率、缩放或主题变化后点到错误位置；正确做法是以可访问性节点为主、坐标为辅，并在点击后校验结果。
- **不做状态确认连续操作**：典型现象是上一步失败会让后续步骤连锁破坏；正确做法是每步执行后校验界面状态，失败就停下并回滚。
- **在真实桌面上直接操作**：典型现象是误删文件或泄露本地数据；正确做法是在隔离虚拟机中运行，限制可访问目录与网络。
