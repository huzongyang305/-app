## 逻辑门速查

| 门 | 表达式 | 输出为 1 的条件 |
| --- | --- | --- |
| 与（AND） | A·B | 全为 1 |
| 或（OR） | A+B | 有一个为 1 |
| 非（NOT） | Ā | 输入为 0 |
| 与非（NAND） | A·B 取反 | 不同时为 1（通用门） |
| 或非（NOR） | A+B 取反 | 全为 0 |
| 异或（XOR） | A⊕B | 两者不同 |
| 同或（XNOR） | A⊕B 取反 | 两者相同 |

## 组合逻辑与时序逻辑

| 类型 | 是否含记忆 | 输出取决于 | 例子 |
| --- | --- | --- | --- |
| 组合逻辑 | 无 | 当前输入 | 加法器、译码器、多路选择器 |
| 时序逻辑 | 有 | 当前输入 + 当前状态 | 触发器、计数器、寄存器 |

| 器件 | 功能 |
| --- | --- |
| 半加器 | 两个 1 位相加，输出和与进位 |
| 全加器 | 带进位输入，可级联成多位加法器 |
| 多路选择器（MUX） | 按选择信号选一路输出 |
| 译码器 | n 位输入选中 2ⁿ 条输出之一 |
| D 触发器 | 时钟边沿锁存数据，构成寄存器 |
| 移位寄存器 | 逐位移动，实现串并转换 |

```python
def half_adder(a: int, b: int):
    """半加器：和 = 异或，进位 = 与。"""
    return a ^ b, a & b


def full_adder(a: int, b: int, carry_in: int):
    """全加器：两个半加器加一个或门。"""
    s1, c1 = half_adder(a, b)
    s2, c2 = half_adder(s1, carry_in)
    return s2, c1 | c2


def ripple_carry_add(a: int, b: int, bits: int = 8):
    """行波进位加法器：逐位级联全加器。"""
    result, carry = 0, 0
    for i in range(bits):
        bit_a = (a >> i) & 1
        bit_b = (b >> i) & 1
        s, carry = full_adder(bit_a, bit_b, carry)
        result |= s << i
    return result, carry          # carry 为 1 表示溢出


assert half_adder(1, 1) == (0, 1)
assert ripple_carry_add(200, 100, bits=8)[1] == 1     # 超过 8 位范围
```

## 常见错误对照表

| 容易写错的做法 | 实际现象 | 原因与正确做法 |
| --- | --- | --- |
| 把异或当成「或」 | 逻辑错误 | 异或：相同为 0、不同为 1 |
| 认为所有门都需要三个门实现 | 电路冗余 | NAND 与 NOR 是通用门，可单独实现全部逻辑 |
| 组合逻辑里引入反馈 | 振荡或竞态 | 反馈必须由时钟控制的时序元件管理 |
| 忽略竞争冒险 | 输出出现毛刺 | 加采样时钟或冗余项消除 |
| 忘记同步复位 | 上电初始状态不确定 | 复位电路把状态置为已知值 |
| 认为行波进位加法器最快 | 高位要等低位进位 | 高速场景用超前进位加法器 |
| 触发器与锁存器混用 | 时序难以分析 | 锁存器电平敏感，触发器边沿敏感 |
| 忽略时钟偏斜 | 建立时间不满足 | 做时序约束与时钟树平衡 |
| 用位运算模拟加法时忽略进位 | 结果错误 | 明确逐位传进位 |
| 认为仿真通过就一定正确 | 未覆盖时序与边界 | 结合时序分析与形式验证 |
