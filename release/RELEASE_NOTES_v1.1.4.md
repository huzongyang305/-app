# v1.1.4

内容质量专项版本：把全库 534 门课的「考点精讲」重建为与当前题库一致的
判断过程，清理历史自动生成模板章节，并为偏薄的课程补充深入讲解。
功能、课程篇数与本地数据格式保持不变，可直接覆盖安装。

## 逐课考点精讲

- **与题库同步**：534 门课全部重建「考点精讲：把测验题还原成判断过程」，
  每道题给出正确判断、判断依据与迁移检查，不再复述旧版元问题
- **模板章节清零**：删除「课程专属精读」「专属复习题库」「故障排查手册」
  等自动生成章节与旧版 HTML 标记，正文改由事实性讲解与练习组成
- **复习结构补全**：每课新增「本课复习清单」，其中 175 课补充
  「逐节复习与自检」、72 课补充「术语速查」、43 课补充「易错点回顾」
- **薄弱课程加厚**：15 门内容偏薄的课程（如操作系统内核架构、IPv6、
  NAT/VPN、实时操作系统、上下文工程等）新增「深入理解」专题

## 安装

1. 下载 `code-learn-v1.1.4-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。

## 校验

`SHA256SUMS.txt` 收录了 APK 的 SHA-256，可用
`sha256sum -c SHA256SUMS.txt` 校验下载完整性。
