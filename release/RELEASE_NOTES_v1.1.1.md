# v1.1.1

界面重设计版本：把全 App 换成 2026 主流的现代极简（Modern Minimal）风格。
功能、课程内容与本地数据格式保持不变，可直接覆盖安装。

## 界面

- **全局只用三种颜色**：主色蓝 `#2F6BFF`、表面白 `#FFFFFF`、画布浅灰 `#F5F6FA`；
  绿 / 红 / 橙收敛为答题对错、删除等必要反馈的语义色
- **统一设计令牌**：卡片 16px、控件 12px、标签 10px、底部弹层 24px 圆角；
  间距一律 4 的倍数，页面水平边距固定 20px
- **柔和阴影**：卡片只保留一层 `blur 20 / y 6` 的低透明度阴影，配 1px 低对比描边
- **卡片式布局**：分类、课程、选项、统计、空状态全部改为同构卡片，去掉旧的竖条与分割线
- **字体层级**：全站统一无衬线，标题 700、正文 400、标签 500~600，数字使用表格数字对齐
- **克制动效**：140 / 200 / 280ms + `easeOutCubic`，并继续遵循系统「减少动画」设置
- 深色模式、平板 NavigationRail、教程分栏与横屏答题布局同步适配

## 修复

- 修复教程代码块右侧滚动区在窄屏（平板分栏）下可能出现的无限高度布局异常
- 修复卡片内嵌 `ListTile` 时水波纹被卡片底色遮挡的问题
- 分类不再各自使用专属色相，语言 / 专题课程统一主色，避免一屏出现多种高饱和色

## 安装

1. 下载 `code-learn-v1.1.1-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。
