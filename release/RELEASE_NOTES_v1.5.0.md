# v1.5.0

学习中心与内容 P0 收口版本：新增学习中心、离线助手与沙箱挑战，并把 609 门课的
错误表、配图和复核排期从「自动生成」推进到「逐课可用」。本地数据格式兼容，
可直接覆盖安装。

## 新增功能

- **学习中心**：按推荐顺序串起分类课程，展示学习热力图、连续学习天数与掌握度，
  入口在「学习」页，可一键继续上次的学习路径。
- **复习计划**：自适应复习间隔（答对递增、答错回落），可在复习计划页查看
  今天要复习的知识点。
- **离线助手**：完全离线的答疑检索（`offline_tutor_service`），不联网、
  不依赖后端，按内置课程内容回答概念与用法问题。
- **沙箱挑战**：13 种语言的代码沙箱新增挑战题与执行追踪，可直接在 App 内
  运行、对拍与查看每一步输出。
- **存储诊断**：新增存储诊断页，展示数据库、内容包与备份占用，可一键迁移。
- **内容包工作台**：支持离线内容包的完整性校验与导入导出。

## 内容改进（P0 收口）

- **常见错误与排查**：215 门课按本课知识点重写为三列表，每门 3 条真实易错点；
  配套重建「故障现场」，`故障现场跨课套话 0 / 引用漂移 0`。
- **配图补全**：67 门只有 1 张配图的课程补齐第二张本课示意图（46 张对照型 +
  21 张流程型），并恢复 7 门图解课被误删的对照图；全库配图引用 1230 条，
  每课至少 2 张。
- **复核排期**：609 门课的「下次复核」从全部同一天改为按批次分散到 12 个月，
  本轮改动过的 280 门课优先；排期表见 `docs/content_review_schedule.md`。
- **正文去重**：压缩 44 门课里重复 12 次的同一句话（共 484 条），
  并把 8 门项目课共用的开场句改成各自领域说法。
- 全库正文 8,018,607 字符、平均 13,166 字符、最短 10,269 字符；3443 道题
  解析均超过 120 字，元问题、模板句、重复题干均为 0。

## 安装

1. `app-release.apk`：ARM 双 ABI 通用包，适配绝大多数 Android 真机。
2. `app-arm64-v8a-release.apk`：64 位 ARM 设备推荐，体积更小。
3. `app-armeabi-v7a-release.apk`：较旧的 32 位 ARM 设备使用。
4. 要求 Android 7.0（API 24）及以上。

发布同时附带 `SHA256SUMS.txt`、`release_manifest.json` 和
`apk_size_report.md`，下载后可以校验完整性与体积预算。

> 说明：内容层的机器校验已全部通过，但 609 门课的**人工复核仍是 0/609**，
> 排期只表示计划时间；复核结论需要真人登记到 `docs/content_review_records.json`。
