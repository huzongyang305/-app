# v1.1.5

内容质量专项版本（P0 收口）：全库 2929 道题的解析统一改为「课程原文 + 判断依据」，
并为每门课补齐可判分的特殊题型。功能与本地数据格式保持不变，可直接覆盖安装。

## 解析去模板

- **全量重写**：2929 道题的解析全部重写，2493 题直接引用课程原文段落，
  其余用课程摘要与题干条件兜底
- **模板清零**：解析中不再出现「把题干放回《…》语境」「错误项只看到了表面现象」
  这类骨架句；重复 5 次以上的模板句与归一化骨架均为 0
- **可读性约束**：解析最短 120 字符，平均约 202 字符；每题都明确写出正确项，
  并且不再使用「选项二/选项 C」这类会在打乱选项后失效的相对指代

## 特殊题型全覆盖

- **534 门课全部有可判分的特殊题型**，共 534 道：
  填空 390、多选 103、排序 19，另有代码题 15、调试题 7
- **本次新增 499 道**：排序 15、填空 385（其中代码填空 330）、多选 99
- **判分字段完整**：填空题带 `accepted_answers`，多选题带 `answers`，
  排序题带 `correct_order`，答题后立即判分并展示解析
- **题量节奏**：每课 3-6 题（3-5 道基础题 + 至多 1 道扩展题）

## 课程正文同步

- 534 门课的「考点精讲」按当前题库重建，新增题目全部进入对应课程正文
- 35 门偏薄课程补充「深度追问与自测」，全部课程正文不少于 6101 字符
- 复习结构与题库保持一致，旧版元问题引用为 0

## 质量验证

- `flutter analyze` 静态检查通过（0 issue）
- 152 项测试通过，覆盖题量、答案下标、特殊题型字段、解析长度、
  模板句去重与每课正文一致性

## 安装

1. 下载 `code-learn-v1.1.5-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。

## 校验

`SHA256SUMS.txt` 收录了 APK 的 SHA-256，可用
`sha256sum -c SHA256SUMS.txt` 校验下载完整性。
