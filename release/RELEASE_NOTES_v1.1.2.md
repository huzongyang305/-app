# v1.1.2

课程代码框体验版本：给教程里的每个代码块加上「全屏展开」，并修掉代码框
底部长期存在的大片空白。功能、课程内容与本地数据格式保持不变，可直接覆盖安装。

## 代码框

- **全屏查看**：代码框工具条新增全屏按钮，点击后整屏阅读，返回时仍停在教程原位置
- **双向滚动**：全屏页纵向滚动长代码、横向滚动长行，代码不再被折断或溢出
- **可选中复制**：全屏页支持长按选择代码，顶部保留一键复制与退出按钮
- **信息更清楚**：顶部显示语言与总行数，`cpp` / `csharp` / `js` 等围栏名会显示为 C++ / C# / JavaScript
- **深浅色一致**：全屏页使用高亮主题深色底，状态栏、导航栏图标自动切换为浅色

## 修复

- 修复代码框底部大片空白：旧布局把行号栏高度叠加进总高度，现在按自然高度布局
- 修复行号与代码行不对齐：行号改用与代码一致的字号与行高，逐行严格对齐
- 修复代码底色在短代码时只覆盖半屏的问题，代码区域底色铺满整块面板

## 质量验证

- `flutter analyze` 静态检查通过（0 issue）
- 151 项测试通过：新增 6 项代码框全屏测试（进入 / 返回、剪贴板写入、超长行不溢出、横屏短视口、语言标签、Markdown 围栏接入）
- 内容完整性、端到端流程、备份迁移、金图视觉回归全部保持通过

## 安装

1. 下载 `code-learn-v1.1.2-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。

## 校验

`SHA256SUMS.txt` 收录了所有 APK 的 SHA-256，可用 `sha256sum -c SHA256SUMS.txt` 校验下载完整性。
