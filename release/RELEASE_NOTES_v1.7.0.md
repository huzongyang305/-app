# v1.7.0

内容修复版本：把「考点精讲」从术语罗列改成逐题版，并让题库与正文彻底对齐。
本次只改课程内容与开发期审计工具，本地数据格式不变，可直接覆盖安装。

## 这次修了什么

- **考点精讲逐题化**：每道题都给出题干、正确项和本课专属判断依据，题库里
  3543 道题的题干 100% 能在对应课程正文里找到；带「正确答案是…」这类生成痕迹的
  解析不再直接搬进正文。
- **重建不再丢东西**：修复截断的术语定义、异常标点（「。；」「，。」）和空小节；
  重建过程中丢失的代码块、配图自动补回。
- **项目课与复习清单补齐**：84 门项目课补「项目专属规格」，每课补 3 条
  `- [ ]` 复习清单，学完可以直接照着自检。
- **题库去重与去模板**：填空重写 361 道、代码选项重写 370 道、题干去模板 599 道、
  解析重写 3543 道；完全相同题干补课程与题号定位，题干重复归零。
- **审计口径同步**：按「没有英文需求」下线 English Overview 与英文精读的强制要求。
