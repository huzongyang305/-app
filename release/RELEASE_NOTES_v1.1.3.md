# v1.1.3

题库质量专项版本（P0）：清掉测验里自动生成的元问题、模板句，以及
「正确项总是最长」这类排版暗示。功能、课程篇数与本地数据格式保持不变，
可直接覆盖安装。

## 测验质量

- **元问题清零**：删除 80 门课里复述课程标题、无法真正作答的
  「《课程名》的……」题目，替换为针对概念、边界条件与失败路径的单选题
- **解析重写**：2027 条带模板痕迹的解析改为「保留课程要点 + 逐项判断
  正确/错误选项 + 回扣题干」的结构，解析少于 120 字符的题目为 0
- **彻底去模板化**：全库 2430 道题中，在解析里重复出现 5 次以上的
  句子为 0 种
- **选项长度校准**：942 道「正确项明显最长（比次长项多 8 个字符以上）」
  的题，通过子句截短或补全干扰项校准，修复后该比例降到 0%
- **答案下标均衡**：单选答案 A/B/C/D 占比约
  24.6% / 26.2% / 24.8% / 24.4%，全部落在 22%–28% 区间
- **题型顺序**：每课测验统一为单选在前，填空、代码、排错等互动题在后

## 质量验证

- `flutter analyze` 静态检查通过（0 issue）
- 151 项测试通过，并新增长期回归门禁：元问题 = 0、模板句 = 0、

## 安装

1. 下载 `code-learn-v1.1.3-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。

## 校验

`SHA256SUMS.txt` 收录了所有 APK 的 SHA-256，可用
