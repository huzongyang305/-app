# v1.1.0

首个公开发布版本：一款完全离线的计算机与编程学习 App，Flutter 编写，支持 Android。

## 内置内容

- 28 个分类、534 篇教程、2430 道测验题、534 张配图，全部打包进 APK，断网可用
- 语言课程：Python、C++、Java、JavaScript、TypeScript、C#、Go、Rust、C、Kotlin、Swift、Shell
- 计算机课程：计算机基础、算法与数据结构、网络、操作系统、数据库、安全与合规
- AI 与 AI Agent、工具链、实战项目等专题课程
- 每篇教程为 Markdown 图文正文，含学习支架、示意图、可复制的高亮代码块、常见坑与练习
- 每课 3~5 道测验题：单选、多选、填空、排序、代码输出与排错，答完立即判分并给出解析

## 学习功能

- 16 条推荐学习路径，按顺序学习、80% 检查点自测、补课与结业项目
- 学习进度、测验正确率、连续签到与成就徽章
- 间隔复习队列：1 / 3 / 7 / 30 天，可开启本地通知提醒
- 收藏知识点与本地笔记
- 关键词搜索：覆盖教程标题、关键词与正文
- 多语言代码沙箱（完全离线）：JavaScript、TypeScript、Python、Lua、SQL、JSON
- 离线朗读：使用系统内置 TTS 朗读教程正文
- 交互式演示：二分查找、冒泡 / 插入 / 选择排序、栈与队列、HTTP 请求链路、数据库事务隔离
- 中英文界面切换、深色模式、平板 NavigationRail 布局与无障碍语义支持

## 数据与备份

- 全部学习数据保存在本机，不依赖任何后端服务
- 备份带 schema 版本，可从系统文件选择器导出 / 恢复，也可导入 JSON 内容包扩展课程
- 启动时执行幂等存储迁移；数据版本高于客户端时进入只读提示页，不会清空数据

## 安装

1. 下载 `code-learn-v1.1.0-universal.apk`（通用包，适配绝大多数 Android 设备）
2. 如需更小体积，可按设备 CPU 架构选择 `arm64-v8a` / `armeabi-v7a` / `x86_64` 分包
3. 在手机上允许「安装未知来源应用」后安装

要求：Android 7.0（API 24）及以上。

## 校验
