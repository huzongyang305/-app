# 内容分级（IARC）填写说明

适用范围：`com.codelearn.study`（计算机与编程学习，1.1.0+2）
应用类别：教育 / 工具（Education）

Play Console 的「内容分级」由 IARC 问卷自动生成，本文件给出逐项预期答案与依据，
提交时以问卷实际选项为准。**最终分级由 IARC 问卷结果决定**，本文件不是分级结论。

## 一、应用内容概况

| 维度 | 实际情况 |
| --- | --- |
| 主要内容 | 计算机科学与编程教程、代码示例、选择题测验、离线代码沙箱、学习进度统计 |
| 是否有用户间交流 | 无。没有评论、私信、论坛、排行榜或任何用户间内容分享 |
| 是否有用户生成内容对外发布 | 无。笔记、收藏、进度只保存在本机，不会上传或展示给他人 |
| 是否联网 | 否。Release 包未声明 `INTERNET` 权限，内容全部内置 |
| 广告 | 无 |
| 内购 / 付费内容 | 无 |
| 位置共享 | 无 |
| 个人信息分享 | 无 |
| 外部链接 | 教程页尾提供官方文档参考链接文本；应用不主动打开浏览器，也不会在应用内加载网页 |

## 三、关于代码沙箱与内容包的特别说明

1. **代码沙箱**：用户可以在「工具 → 代码沙箱」输入并运行代码。代码只在本机 WebView 内执行，
   网络加载已禁用，输出不会上传或分享给其他用户，因此**不构成用户生成内容（UGC）对外分享**。
2. **离线内容包**：用户可主动导入第三方 JSON 课程包。内容仅在本机生效，不会上传；
   但发布者仍需确保随包分发的示例内容合法，如后续内置第三方课程包，须重新核对许可与分级。
3. **通知**：复习提醒为用户可关闭的本地通知，不含营销内容。

## 四、预期分级

在以上答案下，常见结果应为：

| 地区 / 体系 | 预期分级 |
| --- | --- |
| Google Play（IARC 全球） | 3+ / Everyone / 全年龄 |
| 中国大陆商店（如华为、小米、应用宝） | 需按各商店自评问卷单独提交，内容属性为教育类 |

如果商店返回的分级高于预期，优先检查是否误勾选了“用户生成内容分享”“广告”或“在线内容”。

## 五、提交步骤

1. Play Console →「应用内容」→「内容分级」→ 开始填写 IARC 问卷；
2. 按上表选择；应用类别选择「教育 / 参考」；
3. 提交后等待 IARC 邮件与 Play Console 状态更新（通常几分钟内）；
4. 每次新增联网、社交、UGC、广告、内购功能后必须重新填写问卷。

## 六、需要重新分级的情况

- 新增账号、云同步、排行榜、评论、社区等用户间互动；
- 新增联网内容更新、在线视频/音频、外部链接跳转；
- 新增广告、内购、订阅或抽奖；
- 教程内容扩展到可能涉及暴力、赌博、成瘾性机制的主题。
