# Google Play 数据安全表单填写说明

适用范围：`com.codelearn.study`（计算机与编程学习，`versionName` 1.1.0 / `versionCode` 2）

本文件是 Play Console「应用内容 → 数据安全」的逐项填写对照表，供提交前逐条核对。
结论先行：**本应用不收集、不共享任何用户数据。**

## 一、表单逐项答案

| 表单问题 | 选择 | 依据 |
| --- | --- | --- |
| 您的应用是否收集或共享任何必需的用户数据类型？ | **否** | 应用无账号、无埋点、无统计 SDK；Release 包未声明 `INTERNET` 权限，不具备上传能力 |
| 所有用户数据在传输过程中是否加密？ | **不适用**（未收集数据） | 不存在开发者服务器与网络传输 |
| 用户是否可以请求删除其数据？ | **不适用**（未收集数据），可参考下方说明 | 数据只在本机，用户可通过“清除数据/卸载”立即删除 |
| 是否已通过独立第三方验证（如 MASVS）？ | **否** | 项目未申请独立安全认证，选择“否”即可 |
| 是否承诺遵守《家庭政策》？ | 仅在目标受众包含儿童时勾选 | 应用不针对 13 岁以下儿童定向设计；如把受众设为“13 岁以下”，需要额外复核 |

## 二、权限与表单的对应关系

| 权限 / 能力 | 是否影响数据安全表单 | 说明 |
| --- | --- | --- |
| `POST_NOTIFICATIONS` | 否 | 本地通知权限，不产生数据收集；用户拒绝后应用仍可正常使用 |
| `RECEIVE_BOOT_COMPLETED` | 否 | 仅用于重启后恢复已安排的本地提醒 |
| Storage Access Framework | 否 | 用户主动选择的文件才可访问，属于用户发起的一次性授权 |
| `FileProvider`（分享备份） | 否 | 临时只读 URI，分享结束后授权失效 |
| WebView 代码沙箱 | 否 | 已禁用网络与跨文件访问，执行结果不落盘、不上传 |

## 三、本地数据与删除路径

应用在本机保存：学习进度、测验成绩、错题、收藏、笔记、设置、离线内容包，
以及用户主动导出的备份文件（保存在用户自己选择的位置）。开发者服务器上没有任何副本。

用户删除路径（可在隐私政策与应用说明中同步给用户）：

1. Android 设置 → 应用 → 计算机与编程学习 → 存储 → 清除数据；
2. 卸载应用；
3. 手动删除此前导出的备份文件。

## 四、什么情况下必须回来更新这张表

出现以下任一改动时，数据安全表单与 `store/PRIVACY_POLICY.md` 必须同步更新：

- 新增联网、账号、云同步、排行榜、在线内容更新；
- 接入任意统计、广告、崩溃上报、推送或 A/B 测试 SDK；
- 申请新的敏感权限（位置、相册、麦克风、通讯录等）；
- 把用户数据写入开发者可访问的服务端存储。

## 五、提交步骤

1. Play Console → 选择应用 → 「应用内容」→「数据安全」→ 开始填写；
2. 按上表逐项选择，确认“无数据收集/共享”；
3. 在「隐私政策」字段填入已部署的隐私政策网址（内容可取自 `store/privacy_policy.html`）；
4. 提交后在「应用内容」页确认所有条目均为绿色通过状态；
5. 每次发布新版本前，回到本文件复核一次。
