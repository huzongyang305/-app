一、摘要

  • 本应用是纯离线学习应用：不注册账号、不联网、不收集、不上传、不共享任何个人信息。
  • Release 版 APK / AAB 未声明 android.permission.INTERNET，应用本身不具备联网能力。
  • 不包含广告、统计分析、崩溃上报或第三方追踪 SDK。
  • 学习进度、收藏、笔记、测验成绩与设置只保存在设备本地的 Hive 数据库。
  • 备份导出、备份分享、内容包导入只在用户主动操作时通过 Android 系统文件选择器完成。

二、不收集的信息

不收集姓名、邮箱、电话、地址、账号、密码等身份信息；不收集设备标识符（IMEI、Android ID、广告 ID）； 不收集位置、通讯录、相册、麦克风、摄像头、短信、通话记录；不收集学习行为用于广告或分析。

三、本地保存的数据

数据说明位置
学习进度已学知识点、学习时长、连续天数Hive 盒子 app_data
测验成绩每课得分、正确率、错题记录Hive 盒子 app_data
收藏与笔记收藏的知识点、手写笔记Hive 盒子 app_data
设置项深色模式、语言、提醒时间Hive 盒子 app_data
备份文件用户主动导出/分享时生成用户选择的位置或应用缓存

以上数据位于应用私有目录，其他应用无法读取。卸载应用或在系统设置中“清除数据”即可全部删除。

四、Android 权限

权限用途
POST_NOTIFICATIONS发送“复习提醒”本地通知，用户可拒绝或随时关闭
RECEIVE_BOOT_COMPLETED重启手机后恢复已安排的本地提醒

文件读写不使用存储权限：导入、导出、分享均通过 Storage Access Framework， 应用只能访问用户当次明确选择的文件；分享使用临时只读 FileProvider URI。

五、代码沙箱

「工具 → 代码沙箱」在 WebView 中离线执行代码：运行时随安装包打包，网络加载已关闭， 禁止读取其他本地文件，执行结束或超时后立即销毁临时页面。沙箱不会上传代码，也不会写入学习数据。

六、儿童隐私

应用内容面向大众，不针对 13 岁以下儿童定向收集数据；由于不收集任何个人信息， 也不含广告与社交功能，未成年人可在离线状态下安全使用。

七、第三方组件

应用使用 Flutter、Provider、Hive、flutter_markdown、Brython、Fengari、sql.js、Sucrase 等开源组件， 它们只在设备本地运行，不会把数据发送给其作者。完整清单见 store/THIRD_PARTY_LICENSES.md， 应用内“关于 → 开源许可”可查看 Flutter 自动生成的完整许可文本。

八、数据保留与删除

  • 应用不上传数据，开发者不持有任何用户数据副本；
  • 删除方式：Android 设置 → 应用 → 计算机与编程学习 → 存储 → 清除数据；
  • 或直接卸载应用，应用私有目录中的数据会一并删除；
  • 用户自行导出的备份文件保存在用户选择的位置，需要用户自行删除。

九、政策变更

如果未来版本新增联网、账号或统计功能，本政策会同步更新并在应用内与商店页面提示。

English Summary

This app (com.codelearn.study) is a fully offline computer-science learning app.

  • We do not collect, transmit, or share any personal data. No accounts, ads, analytics or tracking SDKs.
  • The release build does not declare the INTERNET permission.
  • Progress, favorites, notes, quiz results and settings live only in the app's private Hive database on your device.
  • POST_NOTIFICATIONS powers optional local reminders; RECEIVE_BOOT_COMPLETED restores them after a reboot.
  • File import/export uses the Storage Access Framework and only touches files you pick. Sharing uses a temporary read-only FileProvider URI.
  • The code sandbox runs in an offline WebView with network disabled and destroys its temporary page after each run.
  • Delete all local data via Android Settings → Apps → Storage → Clear data, or by uninstalling the app.
